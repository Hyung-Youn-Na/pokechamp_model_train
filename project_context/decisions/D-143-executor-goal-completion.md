# D-143 — JEV의 계획 목표 충족 여부 확인

- 상태: Accepted
- 날짜: 2026-10-15
- 승인: 사용자의 목표 충족 확인·불필요한 반복 회피·유효한 미완료 목표 진전 지시 추가 요청

EX-092의 2턴에서 JEV는 Stealth Rock 설치 상태·중복 설치 실패 설명·직전 설치 성공 로그를
받고도 같은 기술을 선택해 실패했다. 당시에는 최초 계획을 재사용했다. 이 기록은 선택 오류의
근거이며, 모델이 설명을 이해하지 못했는지 또는 계획을 과도하게 따랐는지의 원인을 확정하지 않는다.

새 기본 `executor-guidance.txt`에 각 계획 목표의 현재 충족 여부를 확인하고, 충족 조건이
유지되면 불필요하게 반복하지 않으며, 유효한 미완료 목표를 진전시키라는 지시를 추가한다.
조건이 달라지면 완료 여부를 재평가하고 현재 위협·보존 우선순위와 원래 승리 목표를 유지한다.
추가 상태 추적기·후보 필터·계획 수정 없이 JEV의 선택 지침만 변경한다.

새로 읽거나 준비한 설정에 적용한다. 기존 준비본/실험의 동결 지시문·결과·뷰어, v6 원지시문,
GLM 지시문·호출 정책·후보 ID/순서/명령·모델은 보존한다. 실제 모델 호출·배틀은 범위 밖이다.
수행 프롬프트 처치이며 planner만의 효과나 검증된 성능 개선으로 해석하지 않는다.

방법은 [RD](../RESEARCH_DESIGN.md#jev-planner-environment), 실행 경계는
[C-070](../CONTRACTS.md#c-070-jev-planner), 구현·검증은
[EP-149](../exec-plans/completed/EP-149-executor-goal-completion.md)에 둔다.
검토 후 거절한 별도 대안은 없다.
