고정한다. GPU3 소유 서버 시작·정리와 CPU 검증을 포함하며 GPU1의 EX-066 학습은 보존한다.
추가 GPU 예측 대조·재학습·재시도·보충 경기·재수집은 허용하지 않는다.

보장하지 않는다. 이미 확인한 대진의 단일 진단이며 승률 개선이나 전패 원인의 확증이 아니다.
