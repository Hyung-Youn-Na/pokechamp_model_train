# D-021 — 특수 기술 피해의 독립 오프라인 진단

- Status: Accepted
- 날짜: 2026-09-08
- 근거: 사용자가 전달한 「특수 기술 피해 계산 진단」 구현 계획.

현재 개발 팀 1·2·6·12와 고정 prior의 현재 기술군 및 고위험 필수 기술을 대상으로
pinned Showdown Gen9와 @smogon/calc 0.11.0 + ruination-v1을 대조한다.
검증·재현 자료·원인 보고만 수행하며 운영 입력, 계산기, 패키지, submodule은 수정하지 않는다.
Cloud·서버 배틀·승률 비교는 실행하지 않는다.

후보 출처는 prior 전체 수록과 관측 기술이 없을 때 기본 앞4개 선택을 구별한다.
조건·제외·미검증 사유를 실행 전 봉인한다. 정상 면역0, 수치 불일치, 입력 표현 부족,
명시적 미지원, 범위 제외, 검증기 오류를 구별한다. 계산기의 정상0 응답은 지원 증거가 아니다.
명중·난수·타수는 조건부 fixture이며 실행 가능성이나 확률을 새로 추론하지 않는다.

D-020의 새 불일치 즉시 중단 규칙은 이번 진단에 한해서 독립 사례 계속으로 대체한다.
기준 데이터, source identity, 상태 변환, 검증기 오류는 전체 중단한다. 독립 새 fixture로
불일치를 반복 확인한다. EX-017·018은 보존하고 EX-019에 새 evidence를 둔다.
진단 완료는 모든 선정 시험에 결과 또는 명시적 미검증 사유가 있다는 뜻이며 계산기 전체 통과가
아니다. offline_gate_passed=false 및 EP-011 전체 미완료를 유지한다.
