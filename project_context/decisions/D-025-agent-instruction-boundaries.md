# D-025 — 승인 근거와 작업 중단·완료 범위 명료화

- 상태 (Status): 채택 (Accepted)
- 날짜: 2026-09-08
- 근거: 사용자가 현재 대화에서 검토된 추천 조치의 적용을 명시적으로 요청했다.

## 맥락

승인 근거를 plan 파일에만 한정하는 template, 범위를 한정하지 않은 중단 문구,
사용 불가한 보조 스킬을 요구하는 절차가 중복 확인이나 불필요한 미완료를 유발할 수 있다.
RESEARCH_DESIGN의 일부 초기 상태 요약은 뒤에 채택된 운영 실험·진단의 등록을 반영하지 않아
L1-L5 전체 효능 설계의 미정 상태와 혼동된다.

## 결정

- 승인·확인 질문·중단·완료 판단은 [INDEX](../INDEX.md)의 공통 규칙을 기준으로 한다.
  현재 대화의 명시적 승인도 근거로 기록하되 범위·조건·재승인 요건을 유지한다.
- 충돌을 임의로 해결하지 않는다. 그 해결에 의존하는 작업은 중단하고 이미 승인된
  독립 작업은 계속한다. 실험별 전체 중단·재개 승인 요건은 그대로 적용한다.
- 보조 스킬 부재는 사용 가능한 동등 절차로 처리하되 필수 검사와 안전 경계를 보존한다.
- 연구 설계 수정은 현재 상태의 대상과 evidence 연결을 명료화한다. Hypothesis, treatment,
  evaluation/interpretation, gate, denominator 또는 중단 규칙을 변경하지 않는다.
- 현재 로컬 OpenAI Docs에는 로컬 지시 감사·수정 경로를 추가하고 Imagegen에는 CLI 문제에
  의존하지 않는 승인 작업의 계속 수행을 명시한다. 기존 CLI·모델 전환 승인은 유지한다.

## 채택하지 않은 변경

일상 작업에 대한 정식 exec plan 면제는 이번 범위에서 보류한다. Charter invariant, 실행
권한, 실험 재개, 추가 유료 호출, Notion 재활성화는 승인되지 않았다. 로컬 Career Centre는
이미 비활성화되어 있어 명시 호출 전용 전환을 위해 다시 활성화하지 않는다.

## 영향과 증거

[EP-014](../exec-plans/completed/EP-014-agent-instruction-maintenance.md)에서 변경과 검증을 추적한다.
기존 실험의 실패나 미완료를 성공으로 바꾸지 않는다. 로컬 스킬 수정은 이 실행 환경의
설치본에 적용되며 upstream 배포본이나 사용자의 다른 환경에 반영되었다고 주장하지 않는다.
