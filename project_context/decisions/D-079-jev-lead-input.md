# D-079 — JEV 자기 선봉 입력 근거 교정

- 상태: Accepted
- 날짜: 2026-09-21
- 승인: 사용자 EX-050 입력 오류 수정·오프라인 검증 명시 지시

EX-050의 ident 없는 공개 프리뷰와 자기 request ident 연결 실패를 교정한다.
새 입력 jev-choice-v2에서 자기 선봉은 요청 슬롯과 확인된 시작 전 경계로 구성한다.
종족·별명·폼 추정 연결을 하지 않는다. 상태 없음·테라 미적용·미확인은 구분한다.
초기 PP는 검증된 고정 서버/Dex 규칙을 명시 전달한 경우만 사용한다.
과거 jev-choice-v1 투영·prompt 감사는 버전 선택으로 보존한다.
규범 계약은 C-045, 구현/오프라인 증거는 EP-070이다. 새 배틀·API·기존 재개는 승인하지 않는다.
과거 봉인·판정·뷰어와 승패 해석을 변경하지 않는다.
