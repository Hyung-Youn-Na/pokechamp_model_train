# D-026 — EX-017 계열 IO 실험의 사용자 승인 재개

- Status: Accepted
- 날짜: 2026-09-08
- 승인 근거: 현재 대화에서 사용자가 EX-017의 오류로 지연된 실험을 계속 진행하고,
  이전 의도·범위를 추론하여 합리적인 가정으로 자율 실행하라고 명시했다. 실행 권한 조정 후
  다시 이어서 진행하라고 지시했다.

## 결정

EP-011의 미완료 A/B/C 운영 비교를 새 EX-023에서 재개한다. 이는 새 사용자 지시에 따른
별도 실행이며 EX-017/020/021/022의 실패·halt·clock·원자료를 수정하거나 복구하지 않는다.
EX-022 중단 후 검증된 상태 의미·공개 특성 전달 교정을 운영 입력에 사용한다.
요약/행동 thinking은 기존 low, 모델·프롬프트·전략·팀·seed·표본 및 판정 기준은 D-019/D-022를
유지한다. 무효 low/high 진단을 high 채택 근거로 사용하지 않는다.

기존15장면 구조·의미/사후3건 및 전체 회귀 → fake 병렬12판 → Cloud 행동180 및
C 입력 요약/별도48요약 → Cloud smoke12 → 예산 내 비교48판을 수행한다.
새 실행의 최초 Cloud 제출부터 기존과 같은4시간 상한,3시간45분 신규 작업 중지와
15분 보존·정리를 적용한다. 동일 EX-023 내 패치·재검증·재시작은 시계를 초기화하지 않는다.
추가 진단144/72호출은 재실행하지 않는다.

실제 재현된 입력·계산·실행기 오류는 실패 자료를 보존하고 독립 재현·필요한 교정·회귀 후
새 source/단계 identity로 오프라인부터 재검증한다. 실행 중 source 수정과 실패 보충은 없다.
모델 출력·요약 및 provider·무결성 gate는 완화하지 않는다. 해결되지 않은 gate 이후의 배틀은
실행하지 않으며 중단 처리만으로 EP-011을 Completed로 표시하지 않는다.

## 근거와 적용 범위

사용자의 명시적 실험 재개 지시는 INDEX의 승인 재사용 규칙에 따라 다시 확인받지 않는다.
과거 EX-020의 영속 중단 규칙은 해당 실행에 그대로 적용한다. 새 승인과 별도 실행을
연결하기 위해 RESEARCH_DESIGN/C-014/EP-011/EX-023에 이 결정을 명시한다.
L1-L5 전체 효능 설계·minimax·배틀 간 학습과 기존 무효 진단의 재평가는 범위 밖이다.
