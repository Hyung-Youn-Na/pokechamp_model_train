# D-121 — 기절 상태 교정 후 원 예산 재개

- 상태: Accepted
- 날짜: 2026-10-07
- 근거: 실패 측정8건 재시도·원12시간 내 재개 질문에 대한 사용자 “수정후 이어서 진행해주세요.”

관측 생성의 fnt 분류 교정과 독립 CPU40/GPU 검증 결과를 채택한다. 완료uniform32와 P0는
원본 그대로 유지하고 원 실행은 보존한 채 새 source identity에서 이어간다.
실패한 첫8benchmark probe에만 재시도1회를 허용한다. 새 실제 경기 재수집/대체는0이며
학습·평가·gate와 모델 크기/가중치 초기값은 유지한다.

승인 대기 중 원 pilot의 단계 벽시계가 지났으므로, 명시적 재개에 필요한 단계 시계를
중단 전 집행 시간 차감 방식으로 연결한다. 중단 전 pilot 약20.23초·최종화 약11.62초를
차감한다. 검증은 원 시작부터 수정본 독립 GPU 검증 반환까지 약259.63초 전부를 보수적으로
차감한다. 각 단계는 차감된 잔여 한도만 부여하며 새 버전 안의 재개는 그 단계 최초 시계를
갱신하지 않는다. 승인 대기·교정 시간 전체는 원12시간 벽시계에서 계속 소비된다.
원 총 종료 시각은 2026-10-07 14:45:32 UTC이며 연장하지 않는다.

복구 준비는 원 봉인 전수 확인·동일 protocol/catalog/schedule/P0·학습/test0·정확한 실패8probe를
확인하고 recovery.json/단계 소비/원 시계를 새 manifest에 동결한다. 원 버전 디스크와 뷰어도
누적 상한에 합산한다. 후속 중단의 자동 추가 재시도나 새12시간 주기는 승인하지 않는다.
