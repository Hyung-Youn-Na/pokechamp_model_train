# D-051 — 의미를 보존하는 컨텍스트 문서 정리

- 상태: Accepted
- 날짜: 2026-09-14

## 승인 근거와 결정

사용자가 검토 개선 방향을 채택하고 현재 저장소를 기준으로 문서 정리 완료를 요청했다.
STATUS·색인·적용 범위·중복 참조·확인된 증거 링크·읽기 경로·템플릿을 편집한다.
기존 domain authority와 실험 의미는 유지하며 승인 범위나 실험 재개 권한을 확대하지 않는다.
실제 정책 변경과 근거 충돌은 제외한다. 상세 작업·검증은
[EP-039](../exec-plans/completed/EP-039-context-document-maintenance.md)에 기록한다.

## 보존 경계

기존 실험의 동결 protocol과 원자료는 수정·삭제·이동하지 않는다. 과거 승인·예산·gate·
재시도·완료 기준·실패/무효·Blocked를 유지한다. 서브에이전트 두 개의 파일 소유를 분리하고
문서 diff·링크·의미 전후 대조만 수행한다. runtime 테스트와 실험 실행은 포함하지 않는다.
