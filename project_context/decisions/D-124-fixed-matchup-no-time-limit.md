# D-124 — 현재1라운드 실험의 경과시간 상한 해제

- 상태: Accepted
- 날짜: 2026-10-07
- 근거: 사용자 “현재 진행중인 실험에 모든 시간 제약을 걸리 않도록 지침을 바꿔주세요.”

방법 유효성 검증을 위해 EX-078의 경기1200초·검증1시간·학습6시간·최종화1시간·전체8시간
벽시계 상한을 해제한다. 시간 예측값을 실행 허가/중단 조건으로 사용하지 않는다.
경과시간은 비용 기록으로만 남긴다. 단일1라운드32경기·MCTS64/depth32·300턴 검열·
학습step/epoch·자원/무결성·사용자 중지 조건은 시간 상한과 별개이며 변경하지 않는다.
통신 응답 불능 탐지와 프로세스 종료 정리 timeout은 실험 경과시간 예산이 아니므로 유지한다.
EX-078 원실행은31정상/1시간초과·학습0으로 보존한다. 원source/시계/판정을 바꾸지 않고
변경 규범과 구현은 향후 새identity에 적용한다. 이번 지침 변경은 자동 재실행/실패경기 재수집
승인이 아니다. 이전 정상31경기는 보존하고 재개 시 계승 검증 대상이다.
