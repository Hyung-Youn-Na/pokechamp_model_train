# D-101 — 뷰어 결정의 실제 행동 이름

- 상태: Accepted
- 날짜: 2026-09-29
- 승인: 사용자가 현재 생성된 뷰어와 향후 뷰어에서 move ID 대신 기술명·교체 대상명을 표시하도록 요청했다.

Qwen/JEV 실험자 뷰어의 선택·결정 목록·후보 표시에는 결정 당시 관측에서 대응하는
실제 기술명·교체/선봉 포켓몬명과 테라 여부를 사용한다. 현재 EX-063 링크도 갱신한다.
move_ref/현재 기술 슬롯과 후보 설명을 사용하며 다른 결정 시점의 팀 순서나 미래 이력으로
추정하지 않는다. 이름 정보가 없으면 미확인을 표시한다. ID·원명령·q·원 요청/응답은 보존한다.

기존 EX-063 내보내기 버전은 `exports/battle_viewers/ex063-v1`에 원 봉인 그대로 보존했다.
이 변경은 표시 개선이며 연구 처치·배틀 판정·봉인 원자료를 바꾸지 않는다.

[EP-105](../exec-plans/completed/EP-105-viewer-action-names.md)를 따른다.
