# D-112 — Qwen 모방 학습·자기대국 단기 목표 채택

- 상태: Accepted
- 날짜: 2026-10-01
- 후속 관계: [D-115](D-115-abyssal-first-objective.md)가 당면 추진 순서를 부분 대체한다. 아래는 채택 당시 기록이다.

## 맥락과 승인 근거

기존 Qwen/Kev 학습과 Abyssal 후속 정책에 조건부인 q 타깃을 검토하고,
이미 수집한 Smogon/Showdown 리플레이의 모방 학습 및 자기대국을 통한 정책 개선을 논의했다.
사용자는 “모방학습 및 자기대국을 단기 목표로 두자”, “qwen 모델 학습이 목표에 있을텐데
이거를 좀더 구체화한 목표로 추가해두는거지”라고 명시적으로 지시했다.

## 결정

[D-096](D-096-pokemon-training-objective.md)의 포켓몬 전용 학습 목표 아래,
Qwen 기반 구조화 행동 선택 모델(Kev 포함)의 **리플레이 모방 학습 → 자기대국을 통한
정책 개선**을 단기 목표로 구체화한다. 행동 선택과 실제 배틀 성능을 우선 평가한다.
상위 목표는 [CHARTER](../CHARTER.md#immediate-objective), 단계별 산출물·정보 경계·평가 및
미정 설계는 [연구 설계](../RESEARCH_DESIGN.md#pokemon-imitation-self-play)가 소유한다.

기존 리플레이와 CPU 기반 처리를 우선 활용하여 학습 자료 준비 비용을 줄인다.
자기대국에 필요한 모델 추론·업데이트 예산은 후속 실행 설계에서 명시한다.
특정 알고리즘·출력 schema·탐색 방식·학습 환경·체크포인트를 이번 결정으로 확정하지 않는다.

## 근거와 영향

기존의 포괄적 모델 학습 목표를 행동 정책을 배우고 대국 경험으로 개선하는 두 단계에 연결한다.
모방 학습 적합도나 손실 감소 자체를 배틀 성능 향상으로 해석하지 않는다.
기존 q 타깃의 후속 정책 조건과 과거 실험의 판정은 유지한다.

이번 승인 범위는 목표 문서화다. 실제 데이터의 학습용 채택·변환·새 학습·추론·배틀은
후속 bounded plan과 실행 조건에서 구체화한다. EX-066의 기존 실행 조건과 중단 실험의
상태를 변경하지 않으며, 세 RLCD 환경 활용 방향과 L1-L5 장기 목표를 유지한다.

## 증거

- 현재 대화의 명시적 사용자 지시와 데이터 생성 비용·행동 성능 우선순위 논의.
- 기존 리플레이의 규칙 적합성 검토: [EP-100](../exec-plans/completed/EP-100-replay-rule-eligibility.md).
  이 검토는 모방 학습 입력 복원이나 학습용 채택의 완료를 뜻하지 않는다.
- 문서 반영·검증: [EP-114](../exec-plans/completed/EP-114-imitation-self-play-objectives.md).
