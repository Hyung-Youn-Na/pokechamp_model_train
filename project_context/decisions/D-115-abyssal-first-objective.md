# D-115 — Abyssal 상대 효율적 승리를 당면 단기 목표로 채택

- 상태: Accepted
- 날짜: 2026-10-03

## 맥락과 승인 근거

사용자는 현재 모델의 낮은 성능을 근거로 자기대국보다 “일단 초기 목표는 abyssal 상대를
효율적으로 이기는 것”을 우선하자고 지시했다. EX-072는 미학습 모델이 아니라 EX-071의
모방 학습 모델에서 출발했으며, 최종 Abyssal test는2승/20경기였다. 이 결과만으로
자기대국의 일반적 무효성을 입증한 것은 아니다.

## 결정

[D-112](D-112-imitation-self-play-objectives.md)의 단기 단계 중 자기대국 확대의 우선순위를
낮추고 **Abyssal 상대를 효율적으로 이기는 정책 학습**을 당면 목표로 둔다.
D-112의 포켓몬 행동 정책 학습 방향과 모방 학습 단계는 유지하며, 당면 순서만 부분 대체한다.
목표 원문은 [CHARTER](../CHARTER.md#immediate-objective), 평가 방향·미정 조건은
[연구 설계](../RESEARCH_DESIGN.md#abyssal-first-objective)가 소유한다.

## 거절한 대안

자기대국 규모 확대를 당면 우선 과제로 유지하는 방향은 사용자 지시에 따라 후순위로 둔다.
자기대국의 영구 배제나 특정 대체 알고리즘 채택은 결정하지 않았다.

## 근거와 영향

현재 약한 기준 상대 성능을 직접 개선하는 데 학습 목표를 맞춘다. 구체적인 학습 방법,
상대 구성 비율, 초기 체크포인트, 승률·비용 목표와 자원 예산은 후속 설계에서 정한다.
이번 결정은 목표 변경이며 새 학습 실행의 승인이 아니다. EX-071/072의 동결 protocol·
결과 및 D-114는 보존하고 EX-066과 기존 Blocked 실행 조건은 변경하지 않는다.
세 환경 활용 방향과 L1-L5 장기 목표는 유지한다.
