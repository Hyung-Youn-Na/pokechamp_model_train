# D-093 — 스피드 확률 대신 세트별 불확실성

- Status: Accepted
- Date: 2026-09-23
- 승인: 사용자 후속 지시 “확률 보다는 스피드가 우위를 확신할 수 없다는 정보를 … 일단 speed 우위를 확신할 수 없다는 정보만 넣자.”

EP-093 원 요구4의 스피드 우위 확률을 정성적 스피드 비교로 대체한다. D-092의 미결정 확률
가중치를 채택하지 않고 확률 필드를 제거한다. 기존 공개 관측과 일치하는 추천 세트마다 현재
유효 스피드와 자기 기준 빠름/동속/느림을 표시한다. 세트에 따라 결과가 갈리면 우위를 확신할
수 없다고 명시한다. 한 세트 내부의 선택지·공개 HP 불확실성도 보존하며, 모든 후보가 같은
결과여도 유한한 추천 세트 지원 내 일치로 한정하고 모든 실제 세트에 대한 확정으로 표현하지 않는다.

사용자의 Defensive/Offensive Zapdos 예시는 스피드 비교로 전달한다. 실제 행동 순서는 기술
우선도·동속·트릭룸·기타 순서 효과와 함께 해석한다. 분포·확률·고정된 위험 회피 정책은 추가하지
않는다. 나머지 구현·오프라인 검증 범위와 운영 기본 불변은 D-092 그대로 유지한다.
