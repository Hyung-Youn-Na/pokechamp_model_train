# D-027 — low 요약 지시 개선과 IO 재실험

- Status: Accepted
- 날짜: 2026-09-08
- 승인 근거: 현재 사용자가 제시한 「low 설정 유지·요약 지시 개선 후 IO 재실험」 계획의
  구현·검증·Cloud 실행을 명시적으로 요청했다. 같은 범위의 재승인을 요청하지 않는다.

## 결정과 통제

EP-011을 확장하고 별도 EX-024에서 요약·통합 지시만 v1.1.0부터 최대 v1.1.2까지 개선한다.
기존 원본 v1.0.0 파일, 7개 제목, 단일 `<summary>` 형식, 10행동/3요약 주기는 보존한다.
실행의 `evidence.io_summary_prompt_version`으로 선택하고 필드 부재는 원본이다.
배틀/Cloud 검증은 같은 버전과 두 프롬프트 해시를 검사한다. 현재 관측에 따른 actor 진영,
설치 효과의 영향 진영, 원문 기반 발생 턴/행위자/대상/참조를 요약하도록 지시한다.
패킷 말미 턴을 앞선 행동 턴으로 쓰지 않으며 HP 변화·피격 횟수·기절을 구별한다.
원문과 최신 관측을 과거 요약보다 우선하고 소모 아이템/종료 효과를 복원하지 않는다.
근거 없는 규칙·상성·피해 단정은 금지하고 추정은 조건부로 표시한다.

모델 glm-5.3-flash, 모든 역할 thinking low, temperature0, seed100, 출력131072,
provider 기본 context, 배틀/계정/모델10/10/10, retry0을 유지한다.
입력·계산 오류는 독립 재현 후 교정할 수 있지만 유료 제출 source/프롬프트 조합은 합계3개다.

## 단계와 평가

각 source에서 기존300회귀와 추가 검사 → 오프라인15/사후3/요약18입력 → 로컬 병렬12를
통과하고 원본 사건에서 독립 작성한 기준을 Cloud 전에 봉인한다.
C 입력 요약8 → 별도 요약48(30행동 이상4원자료×3요약+1통합×3반복) →
행동180(15장면×B/C×요청동시성1/10×3반복) → Cloud smoke12 → 조건부 비교48을 수행한다.
독립 연쇄/반복은 병렬 실행하고 같은 연쇄의 후속 요약·통합·행동은 선행 의미 검토가
통과한 뒤에만 제출한다. 검토 대기를 영속 기록하며 재개는 응답 재호출 없이 한다.
사실·진영·시점·identity·형식 오류와 사전 필수 사실 누락은 모두0이어야 한다.
검토자는 원자료로 판정하고 추가 Cloud 채점/최적 행동 채점은 하지 않는다.
행동은 출력 오류0·의미 통과·실제 HTTP겹침10·병렬/순차 HTTP p95비율≤2가 필요하다.
smoke는 유효12/12·오류0·실제 동시배틀10·격리/증거 검증이 필요하다.
smoke 기반48판 예상시간에50% 여유를 더해 남은 예산에 들어갈 때 조건당16판을 실행한다.

## 시계·중단·완료

EX-024 최초 Cloud 제출부터4시간을 모든 버전·수정·검토·재검증이 공유한다.
3시간45분 신규 작업 중지/15분 보존·정리이며 시계 초기화는 금지다.
요약 오류는 해당 버전을 즉시 중단·봉인한다. 남은 버전/예산이 있을 때 관측 오류에
근거해 지시를 보완하고 새 source의 사전 검증부터 반복한다. 실패 응답 재질문/보충은 없다.
행동 출력 오류 및 provider·환경·증거 무결성 오류는 전체 실행 중단이다.
배틀에서 버전을 바꾸면 이전 집단을 보존하고 전 단계 및48판 전체를 새로 수행한다.
서로 다른 버전의 성공 표본을 합치지 않는다. 과거 실험의 halt/clock/원자료는 불변이다.

버전별 예정/제출/응답/실패/미실행·역할별 token/HTTP시간·검토 대기/실제 배치 시간을
분리한다. 모든 gate,48판 유효성·C 요약 원문 검토·대응 분석·자원 정리·상태 갱신이
완료돼야 EP-011을 완료한다. 한도/예산 소진 또는 미해결 gate는 미완료다.
개발 자료에서 개선·선택한 지시이므로 결과는 탐색적 비교다.
