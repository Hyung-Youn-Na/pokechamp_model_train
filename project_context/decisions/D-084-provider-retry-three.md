# D-084 — provider 오류 재시도3회 고정

- 상태: Accepted
- 날짜: 2026-09-21
- 승인: 사용자 “provider 오류시 재시도 횟수 3회를 고정해서 적용” 지시

새 JEV 호출의 일시적 provider 오류를 최초 시도+최대3회 재시도(총4시도)로 고정한다.
Ollama/Z.ai의 기존 provider-retry-v2(3회)와 수를 맞춘다. 연결/timeout/429/5xx가 대상이며
인증·요청4xx·입력/응답 계약·판단 오류는 제외한다. 대기는 기존1/2/4초를 사용하고
성공하면 조기 종료하며 기한·취소·누적 예산은 재시도보다 우선한다.
JEV 독립 클라이언트와 새 Session 기본값·시도별 원장/원문·감사를 연결한다.
EX-053 및 과거 봉인 실행의 정책·중단·결과는 보존한다. 본 지시는 구현/무유료 검증 범위이며
기존 실험 재개·새 유료 수집은 수행하지 않는다.
계약 원문은 C-044/045의 D-084, 실행은 [EP-076](../exec-plans/completed/EP-076-provider-retry-three.md)이다.
