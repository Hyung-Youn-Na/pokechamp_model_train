# D-144 — 향후 GLM·JEV 탭·리플레이 통합 표시

- 상태: Accepted
- 날짜: 2026-10-15
- 승인: 현재 사용자 제공 계획의 구현·검증 지시

새 `jev-planner export`의 경기 화면은 GLM 계획 기본 탭과 JEV 요청/응답·상태/후보·턴 로그·
Damage-calc·기술 기록을 왼쪽에, actor 수신 공개 로그의 리플레이를 오른쪽에 배치한다.
좁은 화면은 세로 배치한다. 턴/결정 선택은 일시정지 후 해당 턴 시작으로 이동하며 같은 턴의
강제교체도 같은 위치다. 리플레이 조작·탭 전환은 정보 선택을 바꾸지 않는다.
계획 재사용은 생성 결정을 연결하고 자동/실패/계획 없음/결정 없음 상태를 구별한다.

큰 원문/계산 자료는 결정별 로컬 스크립트로 지연 적재하며 늦은 응답의 덮어쓰기를 막는다.
피해 계산은 observation 감사의 해시와 표시명·계획 추가 전 입력을 검증해 연결하며 재계산하지 않는다.
외부 공식 Showdown 자산 실패 시 로컬 공개 로그를 제공한다. 기존 EX-088/092 원자료·뷰어와
봉인은 보존하며 EX-092는 임시 출력의 읽기 전용 검증 자료로만 사용한다.
새 배틀·모델/프롬프트/호출 정책 변경은 범위 밖이다. 구현/검증은
[EP-150](../exec-plans/completed/EP-150-planner-replay-viewer.md)에서 관리한다.
