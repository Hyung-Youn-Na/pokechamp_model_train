## 목표와 맥락

지금 렌더러(`laya-compact-v11`)는 상대 속도를 매 결정 종족값 범위와 사용 통계로만 다시 추정한다(`features._opp_speed`, `features_v3.first_chance`). 같은 상대와 순서가 관측되어도 `slower?`·`first p.37` 같은 불확실 표시가 남는다. foul-play는 관측 순서로 상대마다 속도 범위를 좁히고(`fp/battle/inference.check_speed_ranges`, `check_choicescarf`) 그 밖의 관측 공개정보로 세트 후보를 줄인다(2026-11-20 비교, 이 계획 진행 절).

## 범위(확정, 모두 포함)

1. **속도 순서 추론**: 상대 포켓몬마다 관측 속도 범위를 경기 내내 유지하고 속도 줄(범위·추정·`first p`)과 `duel`의 선후를 그 범위로 좁힌다. 같은 우선도로 양쪽이 움직인 턴만 쓰고 랭크·마비·스카프·순풍·트릭룸·Quick Claw/특성 우선도 변경 가능성은 제외 규칙으로 둔다. 예상 밖으로 빠르면 스카프 가능성을 올린다.
2. **부정 증거로 세트 후보 줄이기**: 서로 다른 기술 사용 → 구애 도구 아님, 변화기 사용 → 돌격조끼·구애 아님, 스텔스록 피해 → 통굽부츠 아님(받지 않으면 부츠 가능성↑), 턴 끝 회복 없음 → 먹다남은음식·검은진흙 아님, 등장 시 특성 미발동 → 해당 특성 아님, 공격기 사용 뒤 반동 없음 → 생명의구슬 아님.
3. **세트의 결합 일관성**: 슬롯별 독립 주변분포 대신, 공개된 기술과 맞는 세트(통계 세트 또는 foulplay.cc 세트)로 아이템·특성·남은 기술 확률을 조건화한다.
4. **받은·준 피해 역산**: 관측 피해로 상대 스프레드·화력 아이템(구애머리띠·안경·생명의구슬) 후보를 줄인다.
5. **4턴 창 밖 타이머 보강**: Wish·Future Sight 남은 턴, 벽·순풍 남은 턴.
6. **Zoroark 환영 처리**: 기술·피해로 환영을 감지하면 정체를 바로잡고 앞선 추론을 되돌린다.

기준은 foul-play(`.tools/foul-play/src`, 수정하지 않고 규칙만 참고)의 `fp/battle/inference.py`·`fp/battle/protocol.py`·`prepare_battles`이고, 항목마다 foul-play 규칙과의 대응표와 단위 검사를 둔다. 피해 역산(4)은 결정당 지연을 재고(래더 타이머 안), 넘치면 캐시·근사로 줄인다.
