## 질문 및 목적

v2-all 모방 행에 테라 기본 지식 행(규칙 개념과 실제 상태 계산 예시)을 더해 학습하면, 사람의 테라 선택 재현이 나아지고 일반 재현은 유지되는가? 지식 자체는 습득되는가?

## 가설 또는 qualification 목표

- **qualification**:
  - 지식 행의 정답이 모두 재계산과 일치한다.
  - 길이 초과로 제외된 학습 행이 0.5% 이하다.
  - selected의 지식 held-out 정답률이 initial보다 높다.
- **판정**(실행 전 동결, 잠긴 test 1,024, v2-all 행):
  - **주 지표 T**: 사람이 테라를 고른 test 행에서 테라 선택지 확률 합의 차이(EX-124 selected − EX-121 selected). 리플레이 클러스터 bootstrap 95%(10,000회, 시드 20261025)로 본다.
  - **비열등 N**: 전체 행 NLL 차이(EX-124 − EX-121)의 같은 방식 95% 상한 ≤ +0.02
  - **판정 문구**:
    - T 하한 > 0이고 N 충족 → "테라 재현 개선, 일반 재현 유지"
    - T 하한 > 0이고 N 불충족 → "테라 재현 개선, 일반 재현 저하"
    - T 하한 ≤ 0이고 N 충족 → "테라 재현 차이 불분명, 일반 재현 유지"
    - 그 외 → "개선 없음"
- **보조 지표**(판정 외):
  - 테라 가능 test 행에서 사람 테라 행 대 비테라 행의 평균 테라 확률 차이
  - 사람 테라 행 중 테라 1순위 행 수
  - 테라 가능 행의 테라 1순위 비율(사람 3.66%)
  - 라벨 종류별 차이
  - 지식 held-out 정답률(유형별): initial, EX-121 selected, EX-124 selected
- EX-121 쪽 값은 EX-121의 저장된 test 예측을 쓴다. 다시 추론하지 않는다. 지식 held-out만 EX-121 selected로 1회 평가한다.

### 테라 규칙표 (`integration/laya_imitation/tera_rules.md`, `tera_rules.json`)

1차 근거는 Showdown `e64915c0e` 엔진 소스이고, 웹(Serebii)으로 교차 확인했다.

- 배틀당 한 번, 한 마리만 테라할 수 있다. 테라하면 같은 편 전원의 테라가 불가능해진다(`terastallize` → `ally.canTerastallize = null`). 테라한 포켓몬이 기절해도 다시 쓸 수 없다.
- 테라는 그 턴의 기술보다 먼저 처리된다(행동 순서 terastallize 106 < 기술 200).
- 교체 후에도 유지된다(`clearVolatile`에서 해제하지 않음).
- **방어 타입**: 테라 타입 하나가 된다(`getTypes`). Stellar는 원래 타입을 유지한다.
- **자속(STAB)**:
  - 원래 타입은 1.5다.
  - 테라 타입은 1.5다.
  - 테라 타입이 원래 타입과 같으면 2다.
  - Adaptability면 2.25다(ModifySTAB).
  - Stellar 예외는 개념 행에서 짧게만 다룬다.
- **위력 60 보정**: 테라 상태에서 테라 타입이자 원래 타입 아닌 기술 포함, 위력 60 미만인 기술은 60이 된다. 우선도 기술, 연속기, 가변 위력 기술은 예외다.
  - 엔진 조건: `getTypes(true)`가 기술 타입을 포함하고, terastallized이고, priority ≤ 0이고, multihit가 아니다.
- **Tera Blast**: 테라 상태면 테라 타입이 된다. 공격이 특수공격보다 높으면 물리다.
- **정보**: 상대 테라 타입은 테라 전에는 알 수 없다.

### 지식 행 (`tera_knowledge.py`, `datasets/generated/laya-tera-knowledge/v1`)

모든 행은 laya choice 행이다. 정답은 위 규칙, 타입표(`dex_gen9_v2.json`), 고정 calc 결과(v2 정보 캐시)로 계산한다. 전략 판단 라벨은 없다.

- **A 개념 행**(합성 상황 카드, reviewed108 종족, 고정 시드). 유형별 약 3,000행, 총 약 21,000행이다.

  | 유형 | 묻는 것 | 선택지 |
  |---|---|---|
  | A1 | 이번 턴 테라 가능 여부 | 아직 안 씀 / 다른 포켓몬이 씀 / 테라한 포켓몬이 기절 등 |
  | A2 | 테라 후 방어 타입 | 테라 타입 / 원래 타입 / 원래+테라 / 다른 타입. Stellar 포함 |
  | A3 | 테라 후 상대 기술 배율 | x0~x4. 테라 전과 다른 사례 60% |
  | A4 | 테라 시 자속 배율 | 1/1.5/2/2.25 |
  | A5 | 위력 60 보정 결과와 Tera Blast 타입·분류 | – |
  | A6 | 교체 후 테라 유지 시 타입 | – |
  | A7 | 상대 테라 타입을 아는가 | – |

- **B 실제 예시 행**(EX-071 상태 중 내 테라 가능 결정). 상태 텍스트는 `v2-all` 행의 상태를 그대로 쓴다. 유형별 최대 10,000행, 총 최대 40,000행이다.

  | 유형 | 묻는 것 | 선택지·조건 |
  |---|---|---|
  | B1 | 테라하면 상대 공개 공격 기술 중 가장 위험해지는 것 | 공개 공격 기술이 2개 이상이고 최대가 유일한 경우만 |
  | B2 | 기술 X를 테라로 쓰면 피해가 | 늘어남 / 줄어듦 / 같음. 최대 피해 차이 1%p 이내면 같음 |
  | B3 | 테라가 이번 턴 확정 KO 여부를 바꾸는가 | – |
  | B4 | 양측 남은 테라 | 둘 다 / 나만 / 상대만 / 둘 다 없음 |

- **held-out**:
  - A는 종족 10%(digest 순)를 학습에서 뺀다.
  - B는 EX-071 validation과 test 상태에서만 만든다. 유형별 최대 500행이다.
- **길이**: 전체 1,024, head 512, 선택지 48을 넘는 행은 생성 시 버리고 집계한다.
- **생성 결과**(2026-10-23, 학습 전, CPU 59초, 봉인):
  - train: A 21,000행(유형별 3,000), B 36,143행(B1 8,916, B2 9,117, B3 8,110, B4 10,000)
  - held-out: A 2,100행(학습 제외 종족 10개), B 2,142행
  - 길이 초과 0
  - **정답 분포 특성**(재생성하지 않고 기록한다):
    - A1은 "불가"가 75%다. 4가지 사례 중 3가지가 불가다.
    - A2는 테라 타입이 90%다. Stellar가 10%다.
    - A6은 규칙상 항상 "테라 유지"다.
    - A3에는 x4와 x0.25가 없다. 테라 후 단일 타입이기 때문이다.
    - B1은 공개 기술 분포를 따른다(Knock Off, Earthquake 등이 많음).
    - B3은 "바뀜"이 38%다.
- **결합**(구현): 별도 결합 자료를 복사하지 않는다. 학습 시 `v2-all` train에 지식 train 행을 더한다(`training.EX124.extra_train`).
  - EX-124 학습 행 = `v2-all` train(130,411) + 지식 train 행
  - 보정 400행은 모방 행에서만 뗀다(EX-121과 같은 시드와 방식).
  - validation과 선택은 `v2-all` validation 512다.

## 결론 및 후속 작업

- 테라 규칙과 효과 지식은 거의 완전히 습득됐다. held-out 정답률이 96~97%이고, 학습에 없던 종족에도 일반화했다.

- "무엇이 일어나는가"를 아는 것과 "언제 쓰는가"를 고르는 것은 별개라는 점이 확인됐다.
