## 질문 및 목적

1. 어떤 원인이 실제로 판을 지게 했는가(판 단위)?
2. 정책이 실패 표시와 전략 신호를 무시하는 이유가 학습 자료에 있는가, 봇이 스스로 만든 국면에 있는가?

답은 D-209 결정 3~5의 규칙에 넣어 [EX-170](EX-170-laya-v11-data.md)의 자료 조건을 정한다.

## 가설 또는 qualification 목표

탐색 분석이다. 판정 기준은 D-209 결정 3~5가 미리 정한 규칙뿐이다.

| # | 가설 | 맞다면 필요한 조치 |
|---|---|---|
| H1 | 봇이 스스로 만든 낯선 국면: 한 번 실패·정체한 뒤 "직전에 그 기술을 썼다"는 기록이 같은 기술을 다시 끌어당긴다 | 봇 국면 교정 행, 결정 단계 규칙 |
| H2 | 라벨 잡음: 1500 이상 사람도 실패 표시 기술을 고른다(교체 읽기, 실수) | 라벨 정제 |
| H3 | 신호 미학습: `duel lose`, 상대 `boosts`, `opp threat`에 반응하는 행이 드물어 묻혔다 | 해당 행 가중 |
| H4 | 결정적 정책이 읽힌다(argmax, 선봉 고정, Sucker Punch) | 결정 단계 처리(재학습 밖) |
| H5 | 입력 오류·누락(1차 분석에서 확인) | 입력 수정 |
| H6 | 상대·국면 분포 차이: 낮은 레이팅 상대, 학습에서 빠진 국면(Encore·Taunt·구애 고정, 규칙 위반 종) | 자료 범위 검토(보고) |

- **qualification**: 판 기록 보존본의 해시가 원본과 같다. A2의 봇 쪽 수치가 1차 분석 수치(실패 표시가 있는데도 고른 선택 55건 등, 같은 67판 기준)와 맞는다.

## 조건 및 변수

| # | 분석 | 방법 | 가르는 가설 |
|---|---|---|---|
| A1 | 패배 단위 귀속 | 판마다 `board:` 줄로 전력 차 시계열을 만들고 가장 크게 기운 턴을 찾는다. 그 직전 결정에 원인 꼬리표(실패 표시 선택, 표시 없는 실패, Sucker Punch 헛침, 읽힌 교체, `duel lose` 잔류, 능력치 쌓인 상대에게 KO, 테라 오판, 급소·빗나감)를 규칙으로 붙이고, 진 판은 로그로 하나씩 확인한다. 꼬리표별 승·패 판 빈도를 비교한다 | 원인별 비용 |
| A2 | 행동 통계 3자 비교 | 같은 지표를 ① 사람 라벨 ② v10rt가 사람 국면에서 고른 수 ③ 봇이 자기 국면에서 고른 수로 계산한다. 지표: 실패 표시 선택률, 직전 실패 뒤 같은 기술 반복률, 정체 streak 지속률, `duel lose`에서 교체율, 상대 +2 이상일 때 대응, 연속 Protect, 테라 시점, 선봉 분포 | ① 높음 → H2, ① 낮고 ② 높음 → H3, ①② 낮고 ③ 높음 → H1 |
| A3 | 반사실 입력 민감도 | 봇 실패 국면과 사람 행에서 입력을 한 곳씩 바꿔 v10rt 확률 변화를 잰다: `fails` 표시 제거·추가, `streak`·직전 턴 기록 제거, `duel` 승패 뒤집기, 상대 `boosts` 제거 | H1, H3 |
| A4 | 학습 자료 라벨 감사 | `v10-ladder-merged/train.jsonl` 1,242,187행을 한 번 훑는다. 실패 표시 선택지가 있는 행의 사람 선택률(기술별, 직전 같은 기술 여부별), 원본 로그와 맞춘 실제 결과(실패·무효 / 상대 교체), 수정 판정기로 표시가 바뀌는 행 수(표본 5만), 회복 반영 시 `duel`이 바뀌는 행 수, 상대 +2 이상 행의 라벨 분포, 봇 팀 6마리의 등장 행 수, `ladder-index` 레이팅 구간별 차이 | H2, H3, H6 |
| A5 | 읽힘과 결정 규칙 모의 | 같은 상대 첫 대전 대 재대전 승률, Sucker Punch 사용 시 상대 교체율(봇 대 사람 자료). 규칙 후보를 기록된 확률에 적용해 실패 선택이 몇 건 사라지고 정상 선택이 몇 건 바뀌는지 센다 | H4, 규칙 정의 |
| A6 | 래더 재현 장면 세트 | 봇의 실제 입력(요청 본문)을 저장해 어느 렌더러·모델로도 다시 채점할 수 있게 한다. 오답 장면(확정 실패 선택 + A1에서 고른 전략 오판, 허용 행동 표기)과 대조 장면(이긴 판의 결정 표본) | EX-171·172 평가 지표 |

## 결론 및 후속 작업

- H1(봇이 스스로 만든 국면)은 지지된다. 봇 국면의 반복·실패 선택이 사람 라벨과 v10rt 사람 국면 값보다 많다. 기록 문구의 몫은 작고 국면 자체의 몫이 크다.
- H2(라벨 잡음)는 있지만 작다(3.4%). H3(신호 미학습)은 기각한다. 확률 분포는 사람만큼 반응하고, 덜 반응하는 것은 argmax 선택이다.
- H4(결정적 정책)는 한 상대의 4판 사례로 확인된다. 재대전 전체로는 불리하지 않다(14승 10패).
- H5(입력 오류)는 1차 분석대로다. 다만 모델이 `duel` 표기를 거의 쓰지 않아 `duel` 회복 수정의 효과는 작을 것으로 본다.
- H6: 1300 이상 상대에게 5승 13패다. 봇 팀 종의 학습 행은 충분하다.
- D-209 규칙 적용 결과는 [D-210](../decisions/D-210-laya-v11rtc-policy-correction-values.md)에 적었다: 라벨 정제·가중(배수 보정)·봇 국면 교정 행 채택, 테라 지식 비중·상위 레이팅 가중 미채택, Toxic Spikes 판정 유지.
- 사용자 확인이 필요한 것: "교체 확률 합이 가장 유력한 기술보다 크면 교체" 규칙을 래더 비교군에 넣을지. 미리보기 기권패(6마리 미만 팀)의 서빙 수정.
- 한계: 70판, 팀 하나, 하루치 관찰이다. 개입은 A3뿐이다. 사람 국면은 2026-08 중순 경기다.
