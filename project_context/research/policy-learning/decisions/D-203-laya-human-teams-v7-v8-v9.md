# D-203 — laya v7t·v8t·v9t를 사람이 짠 완성 팀으로 Abyssal과 비교(GPU0·1·2)

- 상태: Accepted
- 날짜: 2026-11-02

## 맥락

- EX-150·EX-153·EX-158은 모두 EX-120 일정이다. EX-120 팀은 리플레이(Metamon `modern_replays`)에서 6종족을 가져오고 세부 세트(기술·도구·노력치·테라)를 채워 재구성한 팀이다. 사람이 직접 짠 세트가 아니다.
- 세 비교 모두 "퇴보를 배제하지 못함"이었고, 모델 간 차이는 1~2경기 수준이었다(v7t 112-16, v8t 111-17, v9t 110-18).
- **사용자 지시**(2026-11-02): 정확한 테스트를 위해 실제 팀 세팅으로 v7·v8·v9를 비교한다. GPU0·1·2를 쓴다.
- 선례: EX-145(D-199)가 laya-play 완성 팀 74개로 v5t·v6st·v6ht를 같은 슬롯에서 비교했다(`laya_imitation.teamset_battle`).

## 결정

1. **팀**: laya-play v1.8.0의 사람이 짠 완성 팀 세 묶음을 `smogon`(32) → `blim`(65) → `trained`(69) 순으로 훑어 6종족 서명별 첫 팀만 남긴다. 고정 로컬 Showdown `gen9ou` 검증기를 다시 통과해야 하며, 통과하지 못한 팀은 빼고 목록에 남긴다. 결과는 123팀(smogon 32, blim 62, trained 29), 검증 탈락 0이다. 세 묶음 모두 세부 세트를 추측으로 채우지 않았다(`fill: false`).
2. **일정**: EX-145와 같은 모양이다. 원형 배열 123조합 × 시드 2 × 팀 교환 = 모델당 492슬롯, 시드 20261054(`ex159_*` digest). 게임 전에 봉인한다.
3. **모델**: `laya-v7t`(EX-149), `laya-v8t`(EX-152, 엔진 실패 표시), `laya-v9t`(EX-157, 상대 위협 표시). v8lt(EX-155)는 처음에는 범위 밖이었다. 2026-11-03 사용자 지시로 같은 일정을 GPU3·8106에서 따로 두고([EX-160](../experiments/EX-160-laya-human-teams-v8lt.md)) EX-159 모델과 같은 기본 슬롯으로 비교한다.
4. **GPU 분할**: 쌍(조합·시드)을 진행 순서대로 g0(GPU0·8107), g1(GPU1·8109), g2(GPU2·8108)에 돌아가며 나눈다. 각 묶음은 자기 쌍에서 세 모델을 연달아 둔다(첫 모델 순서는 digest). 묶음마다 서빙 3개·원장·감사가 따로이고, combine에서 합친다. 세 모델이 같은 슬롯을 같은 GPU에서 두므로 같은 슬롯 비교가 유지된다.
5. **판정**(실행 전 동결): 쌍 v8t − v7t, v9t − v7t, v9t − v8t. 같은 슬롯 점수 차이의 조합(123) 클러스터 bootstrap 95%(10,000회, 시드 20261055·20261056·20261057). 하한 > 0이면 "개선", 하한 > −0.05이면 "비퇴보", 그 외 "퇴보를 배제하지 못함". 어느 모델이든 정상 종료가 467/492(95%) 미만이면 판정 보류.
6. **코드**: 새 패키지 `integration/laya_teamset/`. laya_imitation `comparison`의 일정·실행·요약 함수를 그대로 쓰고, v9 서빙은 `laya_threat.battle_v9.register()`로 이 프로세스 안에서만 등록한다. laya_imitation·laya_threat는 고치지 않는다.

## 거절한 대안

- **GPU마다 모델 하나**: 같은 슬롯의 세 모델이 다른 시점·GPU에서 진행돼 묶음별 중단 시 비교 슬롯이 어긋난다. 쌍 단위 분할은 중단돼도 끝난 쌍의 세 모델이 모두 남는다.
- **trained 69팀만 사용**: 모든 팀이 학습 노출 조합이라 일반화를 볼 수 없다. 묶음·노출 여부별 점수를 따로 보고한다.

## 근거와 한계

- 상대는 Abyssal 하나이고 테라를 쓰지 않는다. Abyssal도 같은 사람 팀을 쓴다.
- 123팀 중 69팀은 같은 6종족 조합이 학습 리플레이에 있다.
