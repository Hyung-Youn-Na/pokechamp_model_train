# D-187 — laya v2에 테라 기본 지식 데이터 추가(GPU1)

- 상태: Accepted
- 날짜: 2026-10-23

## 맥락

- [EX-120](../experiments/EX-120-laya-team-generalization128.md)에서 laya(v1)의 테라 사용은 사람보다 훨씬 적었다.
  - 테라를 쓴 경기: laya 18/128(14%), 사람(EX-071 train) 78.8%
  - 결정당 테라 선택률: laya 0.39%, 사람 3.41%
  - 잠긴 test에서 사람이 테라를 고른 20행 중 모델 1순위가 테라인 행은 2행이다.
- 현재 학습 자료에는 테라 규칙이나 효과에 대한 지식이 없다. 모델은 사람 결정 모방으로만 간접 학습했다.
- **사용자 지시**:
  - GPU1을 써서 v2에 테라 관련 지식 데이터를 생성해 학습한다.
  - 전략 라벨은 넣지 않고 기본 지식만 넣는다: 배틀당 1회 자원, 타입 변경으로 상성 반전 등.
  - 필요하면 웹 근거를 쓰고, 실제 상태 기반 계산 예시와 섞는다.
  - 평가는 잠긴 test와 256경기 배틀이다.

## 결정

1. 테라 규칙표를 로컬 고정 Showdown 엔진 소스(1차)와 웹 문서(교차 확인)로 확정한다. 근거 위치를 함께 남긴다.
2. 정답을 규칙표, 타입표, 고정 calc로 계산·검증하는 지식 행을 만든다.
   - **A**: 개념 행. 합성 상황 카드다.
   - **B**: EX-071 실제 상태 기반 계산 예시
   - 전략 판단("지금 테라해야 한다") 라벨은 넣지 않는다.
3. v2-all 학습 행에 지식 행을 더해 EX-121과 같은 시작 모델과 설정으로 GPU1에서 학습한다([EX-124](../experiments/EX-124-laya-v2-tera-knowledge-training.md)).
4. EX-120 일정에서 v2와 v2+테라를 256경기로 비교한다([EX-125](../experiments/EX-125-laya-v2-tera-battle256.md)). 실행은 [EP-212](../plans/EP-212-laya-tera-knowledge.md)가 소유한다.

## 거절한 대안

- **규칙 기반 전략 라벨**: 휴리스틱 편향이 모델에 들어간다. 사용자가 기본 지식만 원했다.
- **입력 렌더러에 테라 효과 문구 추가**: 렌더러가 바뀌어 EX-121과의 비교가 섞인다. 별도 실험 후보로 남긴다.

## 근거와 한계

- 지식 행만 더하므로 EX-121과의 차이는 지식 자료 추가 효과다. 학습량(행 수)도 함께 늘어난다는 한계를 명시한다.
- 지식은 "무엇이 일어나는가"이고 "언제 써야 하는가"가 아니다. 1순위만 고르는 방식에서 사용 빈도가 크게 늘지 않을 수 있다.

## 영향

- `integration/laya_imitation/`에 다음을 추가한다: 규칙표, 지식 생성기, 테라 평가. 자원과 비교 배틀 코드는 GPU와 포트 인자로 일반화하고 기존 동작은 유지한다.
- GPU1(`GPU-c7e2d577-…`)과 포트 8109를 쓴다. EX-121/122의 GPU0·8107과 분리된다.
