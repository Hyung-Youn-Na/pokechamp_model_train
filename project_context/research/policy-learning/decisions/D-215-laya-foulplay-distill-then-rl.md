# D-215 — v11rtc에 foul-play 탐색을 증류한 뒤, foul-play 상대 강화학습으로 다듬는다

- 상태: Accepted
- 날짜: 2026-11-19

## 맥락

- foul-play 상대 점수(D-214 개발 지표)는 v10rt 0.331([EX-174](../experiments/EX-174-laya-v10rt-vs-foulplay-blim128.md)), v11rtc 0.235(중지 51경기, [EX-176](../experiments/EX-176-laya-v11rtc-vs-foulplay-blim128.md)), fp1 epoch-2 0.215([EX-180](../experiments/EX-180-laya-fp1e2-vs-foulplay-blim128.md))다. 입력 판본을 바꾸는 것만으로는 오르지 않았다.
- [EX-181](../experiments/EX-181-laya-v10rt-foulplay-search-regret.md): 같은 자리에서 foul-play 탐색 1순위와 v10rt 선택의 일치는 41.9%, 탐색 반복끼리는 86.9%다. 불일치의 68%에서 탐색 1순위가 laya 확률 2~3위다. 탐색은 교체(24.0% 대 15.4%)와 테라(4.4% 대 1.0%)를 더 고른다.
- 승패 보상만의 강화학습은 과거에 개선을 입증하지 못했다(EX-072~075). 결정당 신호가 없고 foul-play 경기가 느리다(동시 4경기 시간당 약 30경기).
- 사용자 지시(2026-11-19 대화): 증류(탐색 방문 분포를 결정마다 학습)를 먼저 하고, 강화학습으로 다듬는다("1번 증류를 먼저하고 2번으로 다듬는 작업을 진행해주세요").

## 결정

1. **출발점은 v11rtc([EX-172](../experiments/EX-172-laya-v11rtc-training.md) selected)다.** 렌더러 v11, 2,048 / head 768 / 선택지 64는 그대로다.
2. **교사는 foul-play 탐색이다.** EX-181과 같은 방식이다: foul-play `8f541f8`의 `prepare_battles` 표본, 표본마다 poke-engine `monte_carlo_tree_search` 814,000 반복, 스레드 1, 표본 확률 × 방문 비율로 합친 분포. 시간 대신 반복 수로 고정한다.
3. **교사 국면은 사람 학습 자료의 결정 지점이다.** `v11-ladder-merged` train에서 고른 경기의 결정을 fp1 추적기([EX-177](../experiments/EX-177-laya-fp1-data.md) `tracker.py`, 서빙 일치 518/518)로 foul-play `Battle`로 재구성한다. validation·잠긴 test 경기와 평가 Blim 일정(EX-174 collection)은 교사 국면에 쓰지 않는다.
4. **증류는 사람 행과 교사 행을 섞은 soft-CE다.** 교사 행의 목표는 v11 상태 + 교사 분포(`gold`)다. 사람 행은 EX-172의 train 행 일부(가중 그대로)이고, EX-172의 교정 행도 같은 비율로 둔다. 선택 기준은 교사 validation 행의 CE다(개발 목표가 foul-play 점수이므로). 사람 잠긴 test NLL은 보고만 한다.
5. **강화학습은 증류 모델에서 시작하고, 증류 모델에 대한 KL 제약을 둔다.** 상대는 foul-play(평가와 같은 설정), 팀은 평가 Blim 64팀과 겹치지 않는 팀이다. 보상은 승 +1 / 무 0 / 패 −1이다. 세부 값은 해당 EX에 실행 전에 고정한다.
6. **평가는 D-214를 따른다.** 각 후보(증류, 강화학습)를 EX-174 Blim 128슬롯에서 foul-play와 붙여 같은 슬롯에서 v10rt(EX-174)·v11rtc와 비교한다. v11rtc는 EX-176이 중지돼 같은 조건 128경기를 새로 돌린다. 마지막에 foul-play 점수가 가장 높은 후보를 공식 래더에서 확인한다. 모두 보고 전용이다(D-191).

## 거절한 대안

- **승패 보상 강화학습만**: 신호가 드물고 느리다. 과거 개선 미입증.
- **추론 시 탐색 결합**: 모델 개선이 아니고 결정마다 7초가 든다. 별도 후보로 남긴다.
- **fp1 입력에서 출발**: fp1 epoch-2의 foul-play 점수가 v11rtc보다 높지 않았고, 효과 없음 표시·교체 정보에 알려진 결함이 있다(EP-234 2026-11-19 분석).
- **봇 자기 국면(on-policy)을 교사 국면으로**: 증류 단계에서는 사람 국면이 많고 바로 쓸 수 있다. 봇 국면은 강화학습 단계에서 다룬다.

## 근거와 한계

- 교사의 오류(poke-engine의 단순화, foul-play의 2026-10 통계 기반 세트 추론, 평가 함수)도 함께 배운다. EX-181에서 탐색 값의 결과 예측력은 AUC 0.695였다.
- foul-play를 배워 foul-play와 붙이면 "닮아서 이기는" 효과가 섞일 수 있다. 공식 래더 최종 실험이 이를 확인한다(D-214).
- 사람 국면과 봇 국면의 분포가 다르다. 봇이 자주 가는 국면(능력치 최대, 긴 지구전)은 사람 자료에 적다.
