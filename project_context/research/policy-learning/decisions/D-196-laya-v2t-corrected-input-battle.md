# D-196 — laya v2+테라(EX-124)를 재학습 없이 D-195 보정 입력으로 배틀(GPU1)

- 상태: Accepted
- 날짜: 2026-10-27

## 맥락

- [D-195](D-195-laya-item-state-renderer-v5.md)는 상대 아이템 처리에서 결함 두 가지를 확인했다. 하나는 제거된 아이템을 미공개와 구분하지 못하는 것이고, 다른 하나는 미공개 아이템을 가정 세트의 Air Balloon으로 채우는 것이다. 이를 바로잡기 위해 실전 스냅샷에 선택 필드 `item_state`, `status_counter`, `status_source`, `weather_turn`을 더했다.
  - 대응책은 v5 렌더러와 재학습(EX-136)이다.
  - v2 렌더러는 이 필드를 읽지 않는다. 따라서 v2t(EX-124)를 그대로 돌리면 입력과 결과가 EX-125와 같다.
- 사용자 질문(2026-10-27): 이전 모델에 변형된 입력을 넣으면 배틀 성적이 어떻게 달라지는가? 남는 GPU에서 v2t로 확인한다.
- 지금까지 가장 좋은 Abyssal 성적은 v2t다(EX-125 111승 17패). 결정적 경로라 EX-127·129·131·133에서 같은 슬롯 결과가 그대로 재현됐다.
- 문제가 된 사례:
  - 사람 대전 23번 T13: 풍선이 터진 Gholdengo를 상대로 Earth Power가 v2 입력에서 `dmg 0-0%`로 표시됐다.
  - EX-125·EX-131 v2t의 Sleep Talk 실패 43회(사용 100회) 가운데 26회는 그 턴에 깨어나서 실패했다.

## 결정

1. **재학습은 없다.** EX-124 selected 체크포인트(`checkpoint_sha256` 12519d98…)를 실전 입력 두 가지로 서빙한다.
   - `laya-v2t-fix` (`--render v2fix`): `compact_v5.render(value, ('damage','moves','speed','switch'), features_v5.compute(value, calc))`.
     - 텍스트 형식은 v2와 같다. 상대 아이템을 `item_state`로 정한 값만 바뀐다.
     - 바뀌는 값은 제거된 아이템을 없는 것으로 둔 피해, 미공개일 때 Air Balloon을 가정하지 않은 피해, 공개된 풍선·Levitate 상대에게 지면 기술 `x0`, 효과로 공개된 아이템에 대한 Knock Off 위력·`(target item)`, 아이템 속도다.
   - `laya-v2t-info` (`--render v2info`): 위 모듈에 v5 `items`·`counters`를 더한다.
     - `item none (knocked off X)`, `slp t1 rest`, `grassy_terrain t2`처럼 v2t가 학습 때 본 적 없는 문구가 들어간다.
   - v4 모듈(`fails`, `out`)은 두 조건 모두 넣지 않는다. 학습 분포인 v2 형식을 바꾸는 변수를 하나씩만 둔다.
2. **서빙 일치 확인**: 학습 자료가 없는 zero-shot 모드다. 그래서 두 가지를 모두 확인한다.
   - v2 자료(`laya-compact-imitation/v2-all`)의 원본 파일 일치. EX-124가 이 자료로 학습했다.
   - v5 자료(`v5-all`)의 원본 파일 일치. `compact_v5`·`features_v5`가 여기서 나왔다.

   `/health` identity에는 실제 렌더 이름, 학습 렌더 이름(`trained_render`), 렌더러 파일 해시(`renderer_sources`)를 기록한다.
3. **비교 기준**은 이번 실행에서 v2t를 다시 두지 않고 EX-125의 v2t 128슬롯으로 한다. 같은 EX-120 슬롯끼리 비교한다.
   - 근거는 결정적 재현이다. EX-125·127·129·131·133에서 v2t가 모두 111승 17패였다.
   - EX-125 봉인과 `result.json` 해시는 prepare 시점에 동결한다.
4. **판정**(실행 전 동결):
   - 변형별로 같은 슬롯 점수 차이(변형 − EX-125 v2t)를 조합 32 클러스터 bootstrap 95%(10,000회, 시드 20261035)로 본다.
   - 하한 > 0이면 개선, 상한 < 0이면 악화, 그 외에는 구별되지 않음이다.
   - 정상 종료가 120/128 미만인 변형은 판정을 보류한다.
   - info − fix는 같은 실행 쌍비교로 보고만 한다.
5. **자원**: GPU1(`GPU-c7e2d577-573f-0412-1ed6-ad6648efa454`, `gpu1.lock`)과 포트 8109(`port8109.lock`)만 쓴다.
   - EP-218(GPU0·GPU2, 8107·8108)과 겹치지 않는다.
   - 코드는 새 파일 추가와 최소 덧붙이기로만 바꾼다. 기존 렌더러와 EX-137·EX-138 동작은 바꾸지 않는다.
   - 코드 작업은 EX-136이 `training` 단계인 동안에 끝낸다.
6. 오프라인 결과로 배틀을 거르지 않는다([D-191](D-191-no-offline-battle-gate.md)). 사람 대전 132결정 재추론은 보고 전용이다.

## 대안

- **v2t 대조군 128경기를 같은 실행에 더하기**: 결정적 재현이 다섯 번 확인돼 정보 이득이 작고, 384경기면 GPU1 시간이 약 1.5배가 된다. 사용자가 원하면 추가한다.
- **v4t·v5t에 변형 입력 넣기**: v5t는 이미 이 입력으로 학습하고 있다(EX-136). v4t 변형은 이번 질문(최고 성적 모델의 입력 민감도) 밖이다.
