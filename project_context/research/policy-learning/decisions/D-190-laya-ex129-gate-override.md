# D-190 — EX-128 진행 조건 미충족에도 EX-129 배틀 실행(사용자 결정)

- 상태: Accepted
- 날짜: 2026-10-25

## 맥락

- [D-189](D-189-laya-renderer-v3-opponent-sets.md)는 [EX-129](../experiments/EX-129-laya-v2t-v3t-battle256.md)를 [EX-128](../experiments/EX-128-laya-v3-tera-training.md) 판정이 진행 조건(주 지표 S 개선 또는 비열등 N)을 충족할 때만 실행하도록 정했다.
- EX-128 결과(잠긴 test, EX-124 대비 같은 행 차이, replay 클러스터 95%):
  - S(교체 행 365): −0.0341 [−0.0854, +0.0162] → 미충족
  - N(전체 1,024): −0.0115 [−0.0431, +0.020034], 기준 상한 +0.02 → 0.000034 차로 미충족
  - 점추정은 전체, 교체, 강제·pivot 교체 모두 v3 쪽이 낮다(NLL 1.4506 → 1.4391).
- 동결 판정 문구 "전체 저하"는 "비열등 미확인"을 뜻한다. 저하가 관측된 것이 아니다.
- 연결 실행(`scripts/laya-imitation-ep214`)은 조건대로 EX-129를 시작하지 않고 종료했다(2026-10-25T20:19Z).

## 결정

1. **사용자 지시**(2026-10-25): EX-129를 실행한다. 진행 조건 미충족을 기록한 상태로 사전 등록에서 벗어나는 것이다.
2. EX-128의 판정과 문구는 바꾸지 않는다. "진행 조건 미충족"으로 남긴다.
3. EX-129의 설계, 판정 기준(하한 > −0.05 비퇴보), 분모, 일정은 동결된 그대로 쓴다.
4. EX-129 결과는 "진행 조건 이탈 후 실행"으로 표시해 보고한다.

## 거절한 대안

- **EX-128 비열등 여유를 사후에 넓히기**: 사후 기준 변경이다. 판정을 그대로 두고 이탈을 기록하는 쪽이 정직하다.
- **추가 시드 학습 뒤 실행**: 10시간이 더 든다. 배틀 비퇴보 확인은 오프라인 판정과 독립적으로 의미가 있다.

## 근거와 한계

- 미충족 폭(0.000034)이 bootstrap 재표집 잡음 수준이고, 모든 주요 점추정이 개선 방향이다.
- EX-129는 오프라인 판정을 대신하지 않는다. EX-129 결과로 EX-128 판정을 소급해 바꾸지 않는다.
