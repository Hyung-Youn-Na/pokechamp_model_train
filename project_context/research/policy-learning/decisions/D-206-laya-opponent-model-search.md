# D-206 — laya 상대 모델 + 한 턴 탐색(세트 표본 추정), 재학습 없음

- 상태: Accepted
- 날짜: 2026-11-03

## 맥락

- **EP-228 결과**:
  - EX-164 abyssal(교체 갈림길 섞기 대 Abyssal)은 −0.047 [−0.102, +0.008]로 "퇴보를 배제하지 못함"이다.
  - 상성표만으로 만든 읽기 상대는 v8lt를 잘 읽지 못했다. 적중률은 EX-163 16.9%, EX-164 reader 15.9%였다.
  - 사람이 읽은 장면(8번 중 7번 적중)과 차이가 커서, 정직함을 다루려면 상대가 무엇을 둘지 예측하는 모델이 필요하다.
- **학습 자료 집계**(EX-071 train, 2026-11-03):
  - 이미 읽힌 뒤의 결정 행은 21.3%다. 하지만 같은 매치업에서 읽힌 뒤 행동을 바꾼 행은 1,147행이다.
  - 그래서 입력 추가(상대 성향 정보)만으로는 효과가 약할 것으로 본다.
- **사용자 결정**(2026-11-03 대화): 상대 모델 + 한 턴 탐색으로 가고, 상대 세트는 여러 표본으로 추정한다("세트 여러개 표본으로 추정하는 탐색으로 가보자").
- **사용자 확인 사항**(대화): 상대가 모르는 내 정보는 숨기고, 상대는 알지만 우리가 모르는 상대 세트는 표본으로 채운다.

## 결정

1. **상대 시점 입력**: 학습·실전 입력을 만드는 같은 파서(`replay.serialize_state`, Metamon bridge)를 상대 시점으로 돌린다.
   - 상대 팀 자리에는 표본 세트를 넣는다. 내 팀은 파서가 공개 정보만 남긴다.
   - 상대 행동 후보는 표본 세트로 근사한다. 활성 포켓몬의 PP 남은 기술(테라 가능하면 테라 판본 포함)과 기절하지 않은 벤치로의 교체다. 구애 고정·Encore·Taunt·교체 불가는 무시한다.
2. **세트 표본**(`laya_search/sets.py`): usage 고정본(`usage_sets_v3.json`)을 쓴다.
   - 공개된 기술·도구·특성·테라는 고정한다.
   - 나머지 기술은 사용 비율대로 비복원 추출해 4개까지 채운다. 도구·특성·테라·성격과 노력치 배분도 각자의 분포에서 뽑는다.
   - 기술끼리는 서로 독립이라고 가정한다.
3. **단계**:
   - (1) EX-165: 사람(`test`) 4경기의 모든 결정에서 상대 예측을 검증한다. 진짜 세트(oracle)와 표본 8개 평균을 비교하고, 읽기 장면 8개를 따로 본다.
   - (2) 한 턴 이득 계산과 선택 π(a) ∝ prior(a)·exp(λ·EU(a)). 엔진이나 계산기로 이득을 계산하고, λ는 시나리오로 비교한다.
   - (3) 배틀 평가.
   - (2)(3)은 (1) 결과를 보고 별도 EX로 등록한다.
4. **기반 모델**: 개발은 v8lt로 한다. v10t가 나오면 바꿔 끼울 수 있게 렌더러에 의존하지 않게 만든다.
5. **코드 경계**: 새 패키지 `integration/laya_search/`에 둔다. laya_imitation, laya_v10, laya_mindgame, pokechamp/imitation은 바꾸지 않는다.

## 거절한 대안

- **가장 그럴듯한 세트 하나로 채우기**: 추정이 틀리면 예측 전체가 틀린다. 불확실성도 반영하지 못한다.
- **상대 팀 미공개 칸을 `?`로 비우기**: 내 팀 줄은 학습 때 늘 다 채워져 있었으므로, 비우면 학습 분포 밖의 입력이 된다.
- **직접 시점 뒤집기 구현**: 정보 숨김 규칙이 학습 자료와 달라질 위험이 있다. 같은 파서를 쓰는 편이 정확하다.
