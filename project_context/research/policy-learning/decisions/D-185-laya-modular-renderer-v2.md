# D-185 — laya 모듈형 렌더러 v2(기술 변형·속도·교체·피해량)

- 상태: Accepted
- 날짜: 2026-10-22

## 맥락

- [EX-120](../experiments/EX-120-laya-team-generalization128.md)에서 v1 압축 입력 laya는 새 팀 32개 128경기에서도 Abyssal에 우세했다(89-0-39, 0.695).
- **v1 렌더러의 알려진 한계**:
  - 날씨, 필드, 특성, 테라에 따른 기술 변형을 반영하지 않는다(예: snow에서 Weather Ball을 `normal 50`으로 표시).
  - 속도 정보가 없다.
  - 자발 교체 근거가 약하다. EX-118 test에서 voluntary_switch 일치율이 21%였다.
  - 피해량 정보가 없다.
- **사용자 지시**:
  - 네 정보를 모두 넣는다.
  - 정보 유형마다 따로 만들어 이후 조합별 실험을 할 수 있게 한다.
  - 이번에는 4종을 모두 쓴 학습을 한다.
- **사용자 선택**: 시작점은 공개 체크포인트이고 학습 설정은 EX-118과 같다. 평가는 잠긴 test와, EX-120 일정에서 v1과 v2를 같은 실행 안에서 비교한다.

## 결정

1. `features ⊆ {moves, speed, switch, damage}`로 조합되는 모듈형 렌더러 `compact_v2`를 만든다.
   - `features=∅`이면 v1과 바이트 단위로 같다.
   - 모듈 계산값은 정보 캐시에 저장해 이후 조합 자료를 같은 캐시에서 만든다.
2. 이번 학습은 4종 전부(`v2-all`)를 쓴다. 학습 설정은 EX-118과 같고 `head_max_len`만 실측값으로 정한다. 학습과 test 평가는 [EX-121](../experiments/EX-121-laya-v2-all-training.md)이 소유한다.
3. 배틀은 EX-120 봉인 일정에서 v1과 v2 각 128경기를 같은 실행 안에서 비교한다. 조건은 [EX-122](../experiments/EX-122-laya-v1-v2-battle256.md)가 소유하고, 실행은 [EP-210](../plans/EP-210-laya-renderer-v2.md)이 소유한다.
4. 개별 모듈과 조합별 실험은 이번 범위가 아니다. 결과를 보고 별도 EX로 승인받는다.

## 거절한 대안

- **v1 체크포인트에서 이어 학습**: 학습량이 달라져 렌더러 효과와 섞인다.
- **v2만 배틀하고 EX-120과 비교**: 같은 실행 안의 기준선이 없다.

## 근거

- 렌더러 외 조건(시작 모델, 설정, 자료 분할, 일정, 상대)을 고정해야 차이를 렌더러 효과로 해석할 수 있다.
- 모듈 계산과 텍스트화를 분리하면 이후 조합 실험에서 비싼 계산(피해량)을 다시 하지 않아도 되고, 조합마다 같은 수치가 보장된다.

## 영향

- `integration/laya_imitation/`에 v2 렌더러, 정보 계산, 계산기 워커, 자료 생성, 비교 배틀을 추가한다.
- 학습, 평가, 서빙 코드는 판본 인자를 받게 일반화하되 v1 경로의 동작은 유지한다.
- v1 렌더러, 자료, 체크포인트, 봉인은 변경하지 않는다.
- GPU0과 포트 8107만 쓴다.
- **상대 가정 세트**에는 EX-071 결측 보완 corpus의 종족별 최빈 세트를 쓴다. 이는 메타게임 사용 통계에 해당하는 지식이다. EX-120 팀의 개별 세트도 같은 풀 출신이라는 한계는 EX-122에 명시한다.
