# D-191 — 오프라인 test 평가로 배틀 평가를 거르지 않는다

- 상태: Accepted
- 날짜: 2026-10-26

## 맥락

- [D-189](D-189-laya-renderer-v3-opponent-sets.md)는 [EX-128](../experiments/EX-128-laya-v3-tera-training.md)의 잠긴 test NLL 판정을 [EX-129](../experiments/EX-129-laya-v2t-v3t-battle256.md) 배틀의 진행 조건으로 두었다. EX-128은 미충족이었고 [D-190](D-190-laya-ex129-gate-override.md)으로 이탈해 실행했다.
- laya 실험에서 잠긴 test 차이와 Abyssal 배틀 차이는 연결되지 않았다(같은 실행 128슬롯, 조합 클러스터 95%).

| 비교 | test NLL 차이 | 일치율 차이 | 배틀 점수 차이 |
|---|---|---:|---|
| v1 → v2 (EX-121/122) | −0.028 [−0.059, +0.003] | −0.39%p | +0.102 [+0.023, +0.180] |
| v2 → v2+테라 (EX-124/125) | +0.007 [−0.021, +0.035] | +1.46%p | +0.070 [0.000, +0.141] |
| v2+테라 → +효과 (EX-126/127) | −0.001 [−0.026, +0.024] | −0.97%p | −0.070 [−0.148, +0.008] |

  - test 차이는 모두 구별되지 않았고 방향도 배틀과 일관되지 않았다. 배틀에서 유일하게 개선이 확인된 v1 → v2는 test에서 구별되지 않았다.
- **사용자 지시**(2026-10-26): test 평가가 배틀 성능을 반영하지 않으므로, test 평가를 기준으로 배틀 평가를 생략하는 사전 검증 단계를 두지 않도록 매뉴얼을 바꾼다.

## 결정

1. 오프라인 test 평가 결과를 배틀 평가의 진행 조건으로 쓰지 않는다. 학습 실험에 대응하는 배틀 평가가 있으면 오프라인 판정과 관계없이 실행한다.
2. 오프라인 판정과 배틀 판정은 각각 사전 등록하고 따로 보고한다.
3. 배틀 전에 멈출 수 있는 조건은 학습 결함(재로딩 불일치, parity 불일치, 자료 해시 불일치, 학습 중단)과 mock 실패뿐이다.
4. 규칙 원문은 [연구 매뉴얼 §6](../../../RESEARCH_MANUAL.md#no-offline-battle-gate)에 둔다. 동결된 기존 실험(D-189, EX-128)의 판정 원문은 고치지 않는다.

## 거절한 대안

- **진행 조건의 비열등 여유를 넓히기**: test와 배틀이 연결되지 않는다는 근거가 있어 여유 크기의 문제가 아니다.
- **test 대신 다른 오프라인 지표로 거르기**: 배틀과 연결이 입증된 오프라인 지표가 아직 없다.

## 근거와 한계

- 비교가 3쌍뿐이고 상대는 Abyssal 하나다. 배틀과 연결되는 오프라인 지표가 입증되면 이 결정을 새 Decision으로 바꿀 수 있다.
- 배틀 평가를 늘리면 GPU 시간(비교당 약 2.5~10시간)이 늘어난다.
