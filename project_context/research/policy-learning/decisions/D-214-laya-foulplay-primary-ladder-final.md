# D-214 — laya 정책 개선의 개발 목표를 foul-play 상대 점수로, 최종 실험을 공식 래더 대전으로 둔다

- 상태: Accepted
- 날짜: 2026-11-19

## 맥락

- Abyssal 점수는 v7t 이후 0.86~0.88로 포화돼 판본을 구별하지 못한다([EX-162](../experiments/EX-162-laya-v7t-v10t-battle256.md), [EX-168](../experiments/EX-168-laya-v10t-v10rt-battle256.md)). 잠긴 test도 배틀 성적과 연결되지 않았다([D-191](D-191-no-offline-battle-gate.md)).
- foul-play(MCTS 3초 × 병렬 4)는 포화되지 않는 고정 상대다([D-211](D-211-laya-foulplay-opponent.md), [D-212](D-212-laya-foulplay-blim-teams.md)). 공식 래더(계정 nhy_test1629)는 2026-11-15부터 모델별로 돌렸다.

## 결정

1. **개발 목표 지표는 foul-play 상대 점수다.** laya 배틀 정책의 새 처치(입력·학습·서빙 정책)는 foul-play 점수를 높이는 것을 목표로 계획한다. 기본 조건은 EX-174의 Blim 일정 128슬롯(봉인 collection·시드·진영 교환, foul-play `8f541f8`·3,000ms·병렬 4·스레드 1·2026-10 통계, 300턴/600결정, 경기당 1,200초)이다. 같은 슬롯에서 v10rt(EX-174)와의 차이를 함께 보고한다. 다른 일정·상대 조건을 쓰려면 해당 EX에서 이유와 함께 정한다.
2. **최종 실험은 공식 래더 대전이다.** foul-play 결과로 고른 후보를 공식 Showdown gen9ou 래더에서 확인하는 것을 각 계획의 마지막 실험으로 둔다. 래더 실험은 모델·팀·정책(argmax/guard)·서빙 장치·시작·종료 시각을 실행 전에 기록하고, 판 수·승패·레이팅 변화·경기 전 레이팅 기대 대비 초과 승수·상대 평균 레이팅을 보고한다. 계정이 하나라 동시에 한 모델만 둔다. 래더 실행·후보 선택·종료는 사용자 지시를 따른다.
3. **판정 방식은 실험마다 사전 등록한다.** foul-play 점수가 래더로 가는 자동 진행 조건이 되지는 않는다. [D-191](D-191-no-offline-battle-gate.md)은 유지한다(오프라인 test로 배틀을 거르지 않는다). 각 EX는 판정 또는 "보고 전용"을 실행 전에 적는다.
4. **Abyssal 256경기는 주 비교에서 뺀다.** 포화된 상대라 개선 판단에 쓰지 않는다. 실행 결함·퇴보 확인용으로 필요할 때만 등록한다.
5. 이 결정은 이후 새로 등록하는 laya 배틀 정책 계획에 적용한다. 이미 동결된 EX-179·EX-180의 조건·판정 원문은 바꾸지 않는다.

## 거절한 대안

- **Abyssal 점수 유지**: 포화돼 판본을 구별하지 못한다.
- **래더만으로 개발**: 계정 하나로 순차 진행만 되고, 팀·시기·레이팅 구간이 함께 바뀌어 판당 정보가 적다. 30판 차이를 보기에도 하루가 걸린다.
- **잠긴 test NLL**: 배틀 성적과 연결되지 않았다(D-191).

## 근거와 한계

- foul-play와 래더의 비례 관계는 사용자 관찰이다. 정량 근거는 모델 넷뿐이고 그중 셋은 foul-play 경기가 중지되거나 진행 중이다. v11rt·v11rtc와 v10rt의 foul-play 차이도 같은 슬롯 구간이 0을 포함했다(EX-175·176).
- 래더 성적은 팀(`tcd9f36174b`, `t6e257bdf5e`, `t95bfb45561`, `te76a9c3ec1`, `t9ff547d715`, `t9f05bb6c11`), 시기, 레이팅 구간이 모델마다 다르다. 레이팅 기대 대비 초과 승수는 모든 모델에서 ±2 안이다. 래더 레이팅은 실력에 맞춰 움직이므로 승률만으로 모델을 비교하지 않는다.
- foul-play는 한 탐색 봇이다. foul-play에 특화된 약점 공략이 사람 래더 성적으로 이어지지 않을 수 있다. 최종 래더 실험이 이를 확인하는 단계다.
- foul-play 탐색은 재현되지 않는다(같은 슬롯도 결과가 바뀐다).
- 모델 쌍이 더 쌓여 foul-play와 래더가 어긋나면 이 결정을 새 Decision으로 바꾼다.
