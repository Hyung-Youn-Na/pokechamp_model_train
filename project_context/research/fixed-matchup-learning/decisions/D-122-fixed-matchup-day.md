# D-122 — 하루 내 예상 시 고정 대진 실행

- 상태: Accepted
- 날짜: 2026-10-07
- 근거: 사용자 “예상시간이 하루 안이면 실행해주세요.”

EX-076의 3시간 평가 gate에서 중단한 자료는 보존한다. 사용자 후속 지시에 따라
[EX-077](../experiments/EX-077-fixed-matchup-day.md)을 별도 등록하고 전체 예상24시간 이하이면
단일 GPU로1회 실행한다. 완료 pilot으로 예측을 구하며 하한만으로 성공 가능성을 주장하지 않는다.
모델/학습/평가 내용은 유지하고 예산·필요한 pilot 재시도만 명시적으로 변경한다.
동일 tensor/출력을 보존하는 입력 처리 최적화는 검증 후 사용할 수 있다.
EX-076 정상uniform32와 P0는 출처를 연결해 계승하고, 종료 기록이 없는 P0 pilot16은
새 실행에서1회 재측정한다. 미시작16도 수집하여 전체32의 사전 gate를 확인한다.
이전32정상 경기와 새 pilot32를 중복 효능 표본으로 세지 않는다.
새 실행의 첫 GPU 검증부터24시간 상한을 고정하고 자동 추가 실행하지 않는다.
