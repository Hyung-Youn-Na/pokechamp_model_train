## 정기 평가·종료·선택

라운드는 부모1을 포함한 전역 번호다. 라운드당32경기, 새 학습은2~32로 최대992경기다.
출발round1 평가 후4/8/12/16/20/24/28/32마다 탐색 없는 현재 모델 대 초기P0의64경기를
수행한다.16seed블록×A/B×p1/p2, 승1/무0.5/패0 평균 점수다.
개발 seed/행동 RNG는 평가시점 간 공통으로 고정하여 잡음을 줄이고 학습/test와 분리한다.
슬롯/모델해시는 checkpoint별로 구분한다. 출발 평가를 포함하여 최대576경기다.

최소12라운드를 완료하고 아래 첫 조건에서 학습을 끝낸다. 이유가 겹치면 목표→정체→상한
순서로 주사유를 정하고 성립한 모든 사유도 기록한다.

- **목표:** round4 이후 개발 평가에서 평균 점수≥0.65를3회 연속 달성한다.
- **정체:** round1 점수를 anchor로 시작한다. 이후 점수가 anchor+0.02 이상이면
  anchor를 현재 점수로 올리고 정체 횟수를0으로 초기화한다. 그렇지 않으면1 증가한다.
  연속3회 정체이면 종료한다. 작은 개선의 누적은 anchor 기준으로 인정한다.
- **학습량 상한:** 부모를 포함한32라운드를 마치면 반드시 종료한다.

정체 여부와 별개로 모든 완료된 개발 평가의 실제 최고 점수 checkpoint를 선택한다.
동률은 앞 라운드이며 round1도 후보에 포함한다. 각 평가64경기 전부 정상이어야 판정한다.
라운드32경기 모두 정상·전수감사 후에만 업데이트한다. 미완료/무결성 실패에서는
정상 성능 종료로 선택/test에 진입하지 않고 기술적 중단으로 보고한다.
NaN·공유 입력/행동 오류·RAM/GPU/disk 상한·수동 중지는 의존 실행을 중단한다.
전략적으로 나쁜 합법 선택/패배는 정상 학습·평가 표본이다.
