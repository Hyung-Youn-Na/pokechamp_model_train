## 질문과 모집단

새 Abyssal 대 Abyssal80경기의 우리 p2 모든 결정에서 전체 합법 후보별
`q=(win+0.5*draw)/32`를 수집한다. 실제 숨은 상태·양측 고정 Abyssal 후속 정책 조건부 값이며
후보 사이 정규화/softmax는 없다. 본학습·추론 호출·성능 개선 평가는 포함하지 않는다.

자기 팀은 EX-060 manifest 실제 제출 세트의 Zapdos/Hydrapple/Zamazenta/Slowking-Galar/
Tinkaton/Ting-Lu 순서와 모든 세트 값을 보존한다. 상대는 reviewed108 목록에서 고정한다.

| validation | 26893,27448,35809,2838,47268 | 각2, 총10 |
| test | 100817,7627,38229,48494,5742 | 각4, 총20 |

원문 해시/합법성·정규화 제출 세트·결정적 미지정 성별을 저장한다. 동일6종 구성은 같은 그룹,
선택 팀 상호 및 기존 개발 상대와5종 이상 중복은 금지한다. 구성/회복/EV 기반 성향 분류는
경쟁력 검증이 아니다. master seed20260929, namespace EX065에서 split/팀 해시/시드 번호/용도를
SHA-256으로 구분한다. 실제80개 simulator·actor seed를 최초 수집 전에 manifest에 저장한다.

## 동결과 실행

원경기 정책과 후속 정책을 별도 기록하고 source/data/관측 어댑터/simulator 해시를 동결한다.
원경기 행동 actor와 공개 관측만 따라온 우리 후속 actor를 분리한다. 일반 결정은 양측 제출 전,
턴 중 교체는 제출 선택과 pending queue를 보존한다. 후보마다 simulator/양측 actor를 새 복원,
숨은 세트 재표본화0, 관측/반복별 미래 simulator/actor seed를 후보 간 공유한다.
선봉 후보는6개 선봉＋나머지 원순서이고 원정책 전체 preview 순열은 별도 보존한다.
원경기 전체 재현과 모든 root 복원/다음 경계 대조를 통과한 관측만 분기한다.

Showdown 정규 종료까지 진행한다. 정규 무승부와1000턴 자동 무승부는 유효하며 EX-060의
추가300턴 제한은 적용하지 않는다. 정확한 정규 장기전 경고만 허용하고 실제 bigerror는 실패다.
기술 timeout/중단은 결과가 아니며 결정 경계 checkpoint와 동일 RNG로 재개한다.
논리 ID=(관측,후보,반복0…31), 트랜잭션 원장·원자적 결과 저장·모든 시도/재개 이력을 보존한다.
같은 논리 ID 일시 오류 최대3시도. 공유 결함은 의존 수집 중지·교정·독립 회귀 후 영향 관측의
전체 후보×32를 새 버전에서1회 재수집한다. 후보 하나라도32유효가 없으면 관측 전체가 미완료다.

기본32 worker·native threads1, 파일럿에서16/32/48 실제 처리량 비교 후 메모리 여유24GiB를
유지하는 가장 빠른 설정을 선택한다. process 재사용·불변 root 제한 캐시·작은 task ID를 사용한다.
누적 벽시계 상한 없음. 자원 부족은 신규 제출 중지·재개 가능한 보존, seed 교체0.
GPU/외부 API0. 최초 시계·실제 시간/저장량·실패 분모를 유지한다.

## 입력과 분리

[C-051](../CONTRACTS.md#c-051-joint-q)의 pokemon-joint-q-input-v1을 사용한다.
공식 actor 관측/공개 cutoff 이력/자기 팀만 받으며 공통 상태/질문은 관측당1회,
actions[]에 직접 이름/사용자/대상/테라/펼친 후보 결과를 둔다. C3 열 배열과 후보 결과 참조를
펼치고 HP/피해/속도의 대상·단위·조건을 보존한다. 미지원은 unknown, 테라 이득은 계산된
동일 조건 비테라 결과가 있을 때만 비교한다. EX-064 사후 보정본과 당시 모델 결과를 구별한다.
CPU tokenizer만 로드하여 길이를 측정, 무절단·16384초과 별도 보고한다.

inputs/targets/private를 분리하고 후보별 EX-061 형식 export를 ID로 연결한다. 로더는 관측 배치,
가변 후보·q_targets/action_mask와 후보별 변환/순서 변경을 제공한다. 마스크 후보 MSE의 관측
평균이 기본 손실이며 padding은 손실/argmax에서 제외한다.
