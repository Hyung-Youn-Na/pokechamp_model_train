# D-107 — Abyssal Tera 보완 학습 데이터

- 상태: Accepted
- 날짜: 2026-09-30

## 맥락과 결정

기존 데이터는 Tera 후보 평가를 포함하지만 원경기와 분기 후속 정책은 자발적 Tera를
일반적으로 사용하지 않았다. 사용자가 제공한 계획의 구현과 새80경기 수집을 명시했다.
고정 휴리스틱 `abyssal-tera-v1`을 별도 추가하고 원경기·분기 후속 양측에 적용한다.
EX-065 자기 팀·상대20팀·50/10/20 분할을 보존하고 EX067/20260930 seed로 새 수집한다.
정책과 gate는 파일럿 전에 동결하며 test로 조정하지 않는다. 상세 규범은 EX-067/C-053이다.
기존 EX-066 봉인 소스/환경/입력은 보존하고 자료를 자동 병합하거나 새 학습을 실행하지 않는다.

## 근거와 영향

[공식 설명](https://www.pokemon.co.jp/ex/sv/ja/battle/220822_02/)의 타입 변화·Tera Blast와
[Smogon 사례](https://www.smogon.com/articles/ou-tera-blast)의 공격·방어 활용을 규칙화한다.
수치는 검증 전 고정 휴리스틱이며 최적 전략이나 성능 향상을 주장하지 않는다.
새 q는 새로운 후속 정책에 조건부이며 과거 q와 같은 처치로 합치지 않는다.
기록된 대안: 기존 후보 평가만 유지하면 이번 요청의 자발적 사용·사용 이후 관측을 보완하지 못한다.

첫 파일럿의 기절 후 팀 Tera 소모 누락은 승인된 기술 결함 복구 범위로 교정한다.
공개 prefix 기반 팀 소모2값과 현재 개체 표시의 설명을 입력에 추가하고, 정책·seed·평가 기준은
유지한다. 직접 결함5경기와 공통 입력 표현을 위한 재수집10경기를 구분하며 원90,720분기를
보존·최종 학습에서 제외한다. 독립314관측 대조·비공개 격리 검증과 복구 receipt를 통과한
별도 `public-tera-v2`에서만1회 재수집한다. 근거·분모는 EX-067의 복구 절을 따른다.
