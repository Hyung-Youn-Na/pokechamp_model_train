# D-103 — 다경기 공동 q 데이터

- 상태: Accepted
- 날짜: 2026-09-29
- 승인: 현재 사용자가 제공한 EX-065 전체 계획의 구현·검증·수집 지시

고정 자기 팀 p2와 reviewed108 상대20팀에서 신규80경기를 생성하고 모든 우리 결정의
전체 후보를 양측 Abyssal32반복으로 평가한다. 원경기 정책 호출과 후속 초기화 분리,
관측당 공동 입력·마스크된 관측 평균 MSE 로더·트랜잭션 재개를 채택한다.
EX-060의 고정 분모/300턴/4시간 한도는 이 신규 실험에 승계하지 않는다.
본학습·모델 호출·GPU·외부 API는 승인 범위 밖이며 기존 동결 실험은 보존한다.
상세 조건·파일럿 gate·재수집 한도·분모·해석은 [EX-065](../experiments/EX-065-joint-q-data.md),
runtime은 C-051, 진행은 EP-107이 소유한다.
