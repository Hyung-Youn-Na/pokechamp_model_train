# D-030 — 요약을 제외한 improved_io A/B 비교

- 상태: Accepted
- 날짜: 2026-09-09
- 승인 근거: 현재 사용자가 제공한 「요약을 제외한 improved_io A/B 비교」 계획의 구현·검증·실행 지시.

## 결정

새 `io-battle-only-v1` profile, [EP-018](../plans/EP-018-io-battle-only.md),
[EX-026](../experiments/EX-026-io-battle-only.md)을 등록한다. A는 기존 upstream 입력·행동·fallback,
B는 교정 관측·고정 prior·계산기·기존 battle_fixed.txt·엄격한 행동 출력 검증이다.
B의 battle_summary=null, lesson_memory=[]이며 요약·통합 호출과 archive는 0이다.
요약·통합 실험은 분리하며 prompt·전략·prior·계산기 버전은 변경하지 않는다.

EX-016의 Abyssal/OneStep, b01–b04, 양쪽 진영 16대진에 A/B를 대응시키고 순서 seed
20260908로 배치한다. 운영과 동일하게 전체 공개 prefix로 상태를 만들고 최근10결정 원문만
행동 입력에 포함한다. 원문·실제 입력·계산 결과에 근거한 독립 평가를 사전 봉인한다.
짧은 설명에 모든 관측을 나열하거나 최적 행동을 정답으로 요구하지 않는다.

## 단계와 상한

로컬 회귀·15장면 운영 입력 의미 검증·별도 사후 피해3 → 실제 actor fake32 →
B 행동 Cloud90(15×동시성1/10×3) → b04 smoke8 → 시간 추정 통과 시 compare32 순서다.
행동 gate는 출력·사실·진영·시점·계산 근거 오류0, 실제 HTTP overlap10,
병렬 p95≤순차 p95×2다. Smoke는 유효8/8·구성/IO 오류0·실제 동시배틀8·요약0이다.
본 비교는 smoke의 대진별 최대시간으로10자리 일정을 추정하고50% 여유를 포함해 판단한다.

최초 Cloud부터4시간, 신규 작업3시간45분 중지, 정리15분이다. 총4000요청에 A 내부 추가
호출·실패·미확정도 포함한다. 모델 glm-5.3-flash/low/temperature0/seed100/131072출력/
provider 기본 context/timeout300초, 배틀10·계정10·모델10·provider retry0을 유지한다.

D-029/C-018을 적용한다. 유료 재수집 복구는 최대1차, 누적 gate180/smoke16/compare64이며
최초 시계·4000상한을 공유한다. 평가 구현 교정은 온전한 응답을 대칭 재평가하고 rubric
교정은 사후 변경을 공개한 별도 수정 분석이다. 실제 입력·처치·수집 결함은 영향 결과를
무효화하고 독립 재현·수정·회귀 후 영향 A/B 양쪽 대진을 재수집한다. 공유 결함은 전체
영향 대응 집합을 포함한다. 모델 오답을 도구 결함으로 바꾸지 않는다. 영향 범위 입증 실패,
예산/복구 소진은 보존·미완료 보고다. Cloud gate 실패는 배틀 진입을 막고 실제 배틀
출력/provider 오류는 신규 배틀 제출을 중지한다. 합법 완료 설명 오류는 승패 제외 사유가 아니다.

기존 artifact·halt·clock·Blocked는 보존한다. 새 복구 기록/실행 경로를 검증한 후 사용하며
halt 삭제·receipt 덮어쓰기는 금지한다. 전체 B 구성의 탐색적 비교로만 해석한다.

## 완료

사전 gate·smoke8·compare32 및16유효 대응·검토·분석·정리가 모두 필요하다. 조건별
예정/시도/유효/실패/무효/미실행/미확정/복구를 분리하고 smoke·과거 결과는 본 비교에
합치지 않는다. 상대별 draw-adjusted score와 동일 가중 평균·대응 차이·누락, 오류·fallback·
호출/token/HTTP/배치 시간을 보고한다. 미충족 시 EP-018은 미완료로 유지한다.


## EX-026 평가 구현 교정

첫 실제 응답의 두 숫자 범위 대시(U+2013)를 output.py의 ASCII 검사만 거부했다.
C-014와 고정 prompt는 English 1–2문장을 요구하며 ASCII-only 문장 부호를 요구하지 않는다.
원문과 대시만 ASCII로 바꾼 독립 재현에서 같은 합법 JSON의 판정 차이를 확인했다.
D-029 평가 구현 교정으로 새 profile의 언어 검사에 typographic 대시/따옴표를 허용하되
구형 A/B/C 동작·원문/JSON·후보 검증은 보존한다. 실제 응답/입력·수집은 온전하다.

기존1응답은 재호출 없이 대칭 재평가한다. 별도 e1 평가 복구는 원래15입력·prompt·prior·
계산·rubric 동등성을 확인하고 미제출89 ID만 같은 시계/상한에서 수집한다. 원자료와 c0 halt는
불변이며 새 판정은 원본에 연결한다. 이는 이미 받은 표본의 유료 재수집이 아니며 그1차 한도를
소비하지 않는다. 미래 실제 입력/처치/수집 결함의 유료 c1 상한은 계속4000/180/16/64다.


실행 결과 e1은 원본1개를 재사용하고 새3개 제출 후 모델 출력 계약 오류로 중단됐다.
별도 의미 검토에서 시점·KO 계산 오류도 확인했다. [EX-026](../experiments/EX-026-io-battle-only.md)의
4응답과 c0/e1 halt를 보존하며 후속 배틀·재수집은 없다. 결정의 처치·rubric·gate는 완화하지 않는다.
