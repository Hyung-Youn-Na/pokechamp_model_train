# D-179 — 후보 중심 v7와 응답 복구 탐색 실험

- 상태: Accepted
- 날짜: 2026-10-21

## 맥락과 승인

현재 사용자가 제공한 「후보 중심 입력 v7과 GPT-6 Luna 32경기 실험」의 구현·검증·실행 지시를 승인 근거로 삼는다.
EX-112의 과거 Stopped/EP-183 Blocked와 모든 봉인은 보존한다.

## 결정

별도 candidate-action-v1 / jev-choice-v7 입력과 동일 입력 최대3회 응답 시도를 EX-115에 적용한다.
기술 정보·모든 피해 분기를 모델 입력에 보존하고 후보별로 재배치한다. 계산·관측·후보/명령은 유지한다.
통신 재시도는 별도 무제한이며 실행 불가 응답만 복구한다. 합법 선택은 보조 확률과 무관하게 즉시 사용한다.
기존 기본값을 변경하지 않는다. 상세 조건·진입 gate·완료 분모는 EX-115, 구현은 EP-202가 소유한다.

## 근거·영향

사용자가 명시한 정보 보존·총바이트 감소 gate를 실제 요청으로 확인한 뒤 신규32경기를 진행한다.
입력 배치와 응답 정책의 결합 처치이며 단독 인과효과는 주장하지 않는다. 추가 유료 사전호출·기준선·보충0.
거절한 대안은 기록 없음. 공통 RD11.1/11.2, C-018/046/047을 따른다.
