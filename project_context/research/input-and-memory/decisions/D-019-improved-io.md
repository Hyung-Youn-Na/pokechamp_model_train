# D-019 — IO 관측·계산·고정 정책 및 배틀 내 요약 비교

- Status: Accepted
- 날짜: 2026-09-08
- 근거: 사용자가 전달한 「Pokechamp IO 개선 및 병렬 3조건 비교」 구현·검증 지시.

## 결정

A는 EX-016 upstream IO, B는 교정 관측·@smogon/calc 0.11.0·fixed 프롬프트와
첫 오류 중단, C는 B에 행동 10회마다 요약 및 요약 3개마다 통합을 추가한다.
B/C는 최근 10개 행동 구간 이벤트를 공유하며 매 배틀 lesson_memory=[]다.
상대 공개 사실과 고정 Gen 9 prior 추정을 분리하고 상대 정답 및 미래 이벤트는 차단한다.
계산·요약 identity, 후보와 출력 형식을 검증하며 입력/계산/출력/요약 오류는 경기 종료다.
minimax 수리와 배틀 간 학습은 제외한다. 기존 조건의 재현 경로는 유지한다.

모든 실제 배틀은 독립 서버·actor·계산기·메모리로 배틀10/계정요청10/모델요청10,
retry_transient=0을 사용한다. 행동·요약·통합이 하나의 permit 상한을 공유한다.
순서 seed 20260908로 세 조건을 균형 있게 섞고 EX-016 개발 b01–b04의 대응을 유지한다.

## 진행 gate 및 해석

오프라인 15장면·기존 회귀 → fake 병렬12판 → Cloud 15×B/C×1/10×3=180 행동 호출 및
요약/통합 fixture → Cloud 병렬12판 → 비교48판 순서다. Cloud 호출 gate는 오류0,
HTTP 겹침10, 병렬 HTTP p95/순차 p95≤2다. 동시성1은 요청 지연 측정에만 쓴다.
Cloud smoke는 유효12/12·오류0·실제 동시배틀10 및 격리/무결성 통과가 필요하다.
실패하면 원자료를 보존하고 후속 단계를 중단하며 조건 수정/순차 전환/실패 보충하지 않는다.
첫 Cloud 요청부터4시간,3시간45분에 신규 요청과 작업을 중지·취소하고15분 정리한다.
비교는 smoke 시간 기반10자리 추정×1.5가 남은 예산에 들어갈 때만 시작한다.
배치 경과와 자원 시간합을 구별하고, 조건별 예정/시도/완료/실패/미실행 및 대응 누락을 보고한다.
상대별 (승+0.5×무승부)/유효완료와 두 상대 동일가중 평균, 완료 대응 block 차이를 보고한다.
이미 분석한 개발 자료의 탐색적 비교이며 효능·우월성 확증은 아니다.
