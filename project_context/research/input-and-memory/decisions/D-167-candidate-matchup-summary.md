# D-167 — 후보별 현재 상대 적용결과 보강

- 상태: Accepted
- 날짜: 2026-10-20
- 승인: 사용자 후보별 현재대면 상성·효과 요약 추가 방향 동의

## 결정·근거

EX110 저장 입력에 상성표·현재피해0이 있는데도 면역기술을 선택한 사례를 확인했다.
정보 누락이 원인이라고 확정하지 않고, 후보와 현재대면 정보를 연결하는 입력표현 개선을 채택한다.
기존 v6의 모든정보/원지시문/후보를 유지하면서 후보별 current_matchup 요약만 추가한다.
전체표 제거·선택지 필터·강제대체는 적용하지 않는다. 현재상태와 가정적 상대Tera 결과를 구분한다.

타입표상배율, 공개된도구/특성/상태에 의한 차단, 기존계산기 조건부피해를 별도 필드로 제공한다.
변화기는 일반피해타입표를 일괄적용하지 않고 지원한 기술규칙만 사용한다. 미상/지원밖은unknown.
모델 선택/승률 개선은 검증되지 않았고 실제유료비교는 이번구현 범위에 포함하지 않는다.

## 영향·증거

진행중/과거실험의 v6/봉인은 유지하고 독립 candidate-matchup-v1 overlay를 명시 선택한다.
규범은 [C-081](../CONTRACTS.md#c-081-candidate-matchup),
진행/전후예제/검증은 [EP-182](../plans/EP-182-candidate-matchup-summary.md)에 둔다.
