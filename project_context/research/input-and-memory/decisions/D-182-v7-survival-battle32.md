# D-182 — 생존·교체 비용 v7 GPT-6 Luna 32경기

- 상태: Accepted
- 날짜: 2026-10-21

## 맥락·승인

사용자 「해당 입력으로 32경기 gpt 6 luna decision 실험을 시작해주세요」를 승인 근거로 삼는다.
D-181/EP-205 개정 입력을 새 EX-117에서 실행한다. EX-115의 원자료·결과·봉인을 유지한다.

## 결정

EX-115와 같은 GPT-6 Luna Decisions·32대진/16쌍·팀·seed·순서·Abyssal·Gen9 OU 및
통신/응답 정책을 사용한다. 처치 차이는 생존 판단·교체 기회비용 지시문이다.
실행기·뷰어의 실험 ID/출력 경로 연결은 새 실행을 구분하기 위한 변경이다.
기존 EX115의 바이트 감소 gate는 재적용하지 않고, instructions 외 정보 동치와 증가량을 확인한다.
세부 조건·진입 검증·중단/복구·완료는 EX-117, 구현·실행은 EP-206이 소유한다.

## 근거·영향

추가 유료 사전호출·새 기준선·보충/재수집은0이다. API 본32슬롯만 실행한다.
과거 EX115와의 탐색 비교로 실행 시점·모델변동·개발대진·경기전개 차이를 통제하지 않는다.
개정 효능·일반 승률 개선은 사전 전제하지 않는다. 병행 EP203 학습/GPU 자원을 변경하지 않는다.

## 거절한 대안

기존 EX115 경로 덮어쓰기 및 과거 총바이트 감소 gate의 소급 적용은 처치/증거 구분에 맞지 않는다.
