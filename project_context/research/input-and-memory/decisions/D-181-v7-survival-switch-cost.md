# D-181 — v7 생존 판단과 교체 기회비용 지침

- 상태: Accepted
- 날짜: 2026-10-21

## 맥락·승인

사용자가 제공한 「v7 지시문에 생존 판단과 교체 비용 연결」 계획의 구현·검증 지시를 따른다.
[D-179](D-179-candidate-action-v7.md)의 개발용 지시문에서 일반적인 스피드 결과 고려 문장을
구체적인 생존·행동 가치 비교로 대체한다.

## 결정

상세 스피드 설명 직후 사용자 지정 영어 두 문단을 한 번만 넣는다. 행동 효과를 평가하기 전에
행동 시점까지 생존할 수 있는지 남은 최대 HP 대비 비율과 제공된 받는 피해 범위로 검토한다.
일반 교체의 생존·후속 대면 이득과 포기하는 행동·진입 위험을 함께 비교하고,
강제 교체와 피벗 기술을 구분한다. 위험하면 무조건 교체하라는 지시로 해석하지 않는다.
기존 우선도·스피드·피해 계산 조건·교체 상태 변화 규칙은 유지한다.

## 영향·한계

개발용 prompt.txt만 개정하며 입력 필드·계산·후보·실행 정책·프로필 이름은 유지한다.
기존 prompt_sha256으로 개정 전후를 구분한다. EX-115 수집 당시 동결본·원자료·결과는 보존하고
사람용 EX-115 설명서는 동결 지시문을 참조한다. 과거 총바이트 감소 gate를 새 지시문의
성질로 승계하지 않는다. 추가 API·배틀·성능 평가와 기존 중단 실험 재개는 포함하지 않는다.

## 거절한 대안

위험하면 교체를 강제하는 규칙은 사용자가 지정한 행동 기회비용 비교와 맞지 않아 채택하지 않는다.

## 근거·증거

공통 RESEARCH_DESIGN의 처치 식별·해석 경계와 C-006을 유지한다.
[EP-205](../plans/EP-205-v7-survival-switch-cost.md)에 구현·오프라인 전달·길이 검증을 기록한다.
