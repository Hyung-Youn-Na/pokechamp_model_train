# D-035 — 계산기 입력 전체 조사와 결함 수정

- 상태: Accepted
- 날짜: 2026-09-10

## 맥락과 승인

사용자가 제공한 「계산기 입력 전체 심층 조사 및 버그 수정」 계획을 구현한다.
EX-029에서 확인된 재등장 Dauntless Shield 결함과 전체 입력 경로의 정확성을 조사한다.
기존 중단 실험을 재개하지 않고 별도 EP-023·EX-030으로 등록한다.

## 결정

원시 자기 request·공개 prefix → 관측 → 상대 가설 → worker 요청/응답 → 최종 LLM 입력을
각 경계에서 독립 검증한다. 확인된 지원 범위 결함은 같은 작업에서 수정한다.
발동·소비 이력은 battle별 Pokémon identity에 연결하며 최근10결정 밖도 유지한다.
불명확한 이력을 미발동으로 간주하지 않는다. 매 등장/배틀당1회 특성을 구분한다.
새 의미·필드는 입력 검증기·설명서·provenance에 새 버전으로 함께 반영한다.

## 범위와 해석

parent integration·프로젝트 소유 검증 코드만 변경한다. pinned submodule·설치 라이브러리 직접
편집, prior 통계/전략 조정, 전체 Gen9 시뮬레이터 구현은 제외한다. 피해는 명중 조건부이며
행동 실행 예측이 아니다. Showdown 비공개 상태는 독립 테스트 정답에만 사용한다.
EX-028 435건·EX-029 201건(무응답 포함)을 각각 공개 cutoff까지 재생하고 별도 영향 분석한다.
기존 원자료·주석·봉인 보고서·halt·원장·6개 Blocked는 보존한다. 유료 호출/재실험/재수집은0이다.
미해결 정확성 결함이나 설명되지 않은 불일치가 남으면 완료로 표시하지 않는다.

## 대안과 근거

조사 보고만 남기고 수정을 다시 승인받는 대안은 사용자의 명시적 완료 지시에 맞지 않는다.
과거 모델 행동·승패를 수정 입력으로 복원했다고 주장하지 않는다.
