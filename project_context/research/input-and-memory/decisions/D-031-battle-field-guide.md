# D-031 — B 행동 입력 필드 설명서

- 상태: Accepted
- 날짜: 2026-09-09
- 승인 근거: 현재 사용자가 제공한 「Battle state 필드 설명서를 프롬프트에 포함」 계획의 구현·로컬 검증 지시.

## 결정

요약 없는 B에 영문 필드 설명서를 포함하는 행동 prompt v1.1.0을 추가한다. 단일 버전 관리
필드 자산에서 경로·자료형·단위·시점·공개/추정·빈 값/불확실성 규칙을 일정 순서로 렌더링한다.
기술·특성·아이템의 효과 사전, 장면 정답과 추천 행동은 포함하지 않는다.
기존 battle_fixed.txt와 A/요약 실험은 보존한다. 새 B prepare 기본은 v1.1.0,
버전 없는 과거 설정은 v1.0.0이다. 공통 조립·필드 검사·hash identity를 준비/worker/actor에
연결하며 설명 없는 중첩 필드와 원문 request JSON 경로는 요청 전에 거부한다.

[EP-019](../plans/EP-019-battle-field-guide.md)는 구현·로컬 검증만 수행한다.
EX-026의 응답·halt·최초 시계·Blocked와 모든 기존 자료는 보존한다. Cloud 재호출·실배틀
재개·평가 기준 변경은 승인하지 않는다. 모델 오류 감소나 Cloud gate 통과를 주장하지 않는다.
