# D-092 — JEV 오프라인 입력 표현 개선

- Status: Accepted
- Date: 2026-09-22
- 승인: 현재 사용자의 명시적 구현·오프라인 검증 요구사항

운영 jev-choice-v3와 별개 버전 jev-offline-v1을 만든다. 효과 인라인, 자기 기술 슬롯 통합,
역할 DB의 조건부 역할, 타입 상성 및 방어 타입, 내부 필드 제외, unknown 구분, 공식 로그 변환을 채택한다.
EP-082 계산 방식은 오프라인 재사용하며 상대 공개 기술만 노출한다. 자기 벤치 축약은 일반 턴 비교 옵션이고 기본 상세다.
선봉·강제교체 축약은 채택하지 않는다. 스피드 확률의 가중치 가정은 아직 미결정이며 사용자 확인 전 수치를 만들지 않는다.
운영 전환·유료 호출·새 배틀·판단 성능 주장은 범위 밖이다. 검증 및 진행은 EP-093을 따른다.

2026-09-23 후속 지시: 확률 요구·대기 상태는 [D-093](D-093-speed-uncertainty.md)의 정성적 불확실성 표시로 대체되었다.
