current_pp_source만 재귀 제거한다. PP 값·이유·검증, 관측·후보·명령·choice-action-v3를 유지한다.
v1/v2와 EX-051/052 원자료·봉인·뷰어를 보존한다. EP-062/064의 Blocked 범위를 확인했으며 재개하지 않는다.
