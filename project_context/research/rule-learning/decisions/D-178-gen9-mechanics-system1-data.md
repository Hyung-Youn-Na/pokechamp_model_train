# D-178 — 우선순위별 규칙 적용과 정보 충분성 자료

- 상태: Accepted
- 날짜: 2026-10-21
- 승인: 사용자 5개 데이터 우선순위 순서 System One 생성 지시

EP201은 특성/도구→교체/잔여→기술 조건→정보 충분성→한 턴 결합 순으로 합성 규칙 학습pool을 구성한다.
명시된 제어 조건과 가능세계의 결과만 라벨로 사용한다. 알려지지 않은 실제 조건을 추정하여 확정 정답으로 만들지 않는다.
4순위의 정보 부족은 명시 가능세계에서 결과가 갈리는 경우이고, 결과가 같으면 숨은 값이 있어도 확정 가능하다.
설명 생성 없이 선택 CE 형식을 사용한다. 기존 학습/평가 분할·효능 주장은 변경하지 않는다.
