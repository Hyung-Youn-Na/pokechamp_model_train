# D-175 — 실제 리플레이의 관측 KO 결과 학습자료

- 상태: Accepted
- 날짜: 2026-10-21
- 승인: 사용자 실제 리플레이 KO 상황 System1 문제 생성 요청

## 결정·근거

EP198에서 공개관전자정보와조건으로지정한공격을입력으로, 실제직접KO발생을라벨로하는새자료를구성한다.
단일리플레이결과는확정KO/확률100%/반사실행동가치/최적행동근거가아니다.
미래행동이름은명시된질문의조건으로만사용하며미래피해/급소/명중/승패·숨은세트를입력으로소급하지않는다.
과거합성규칙자료와별도원천/해석경계를유지한다. 보관dataset train만사용하고기존평가자료보존·알려진중복제외를수행한다.

## 영향

양성/음성경기별제한표집은자연KO빈도나확률보정평가를대신하지않는다. 자료는학습pool이며실제학습은승인범위밖이다.
공개로그의불완전정보·알수없는기존중복·역사적규칙·원천라이선스미선언의한계를보존하고외부게시하지않는다.
