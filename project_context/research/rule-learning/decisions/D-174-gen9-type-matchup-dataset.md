# D-174 — Gen9 타입 상성 전수 자료

- 상태: Accepted
- 날짜: 2026-10-21
- 근거: 사용자 Gen9OU 모든 타입 경우의 수 상성 계산 학습자료 생성 요청

## 결정

EP192의 독립 gen9-type-matchup-v1 자료를 생성한다. 18표준타입의 단일/복합 전조합과 공격타입을 기본으로,
일반테라·스텔라의 방어/공격 상태를 확장으로 제공한다. 원천은 고정된 로컬 Showdown Gen9 규칙이다.
모든 조합은 합성 타입 문제이며 실제 OU합법 포켓몬 종/세트 표본이라고 주장하지 않는다.
타입 상성만 계산하며 자속/특성/도구/특수기술 피해효과와 모델학습/평가를 포함하지 않는다.

## 이유·영향

기존 D159의 표본 규칙QA와 Stellar 제외 범위는 보존한다. 신규자료는 전수열거된 학습pool이다.
기존 test와 독립이라고 보장하지 않으며 후속 학습 시 규칙/상성의 중복을 고려해야 한다.
같은 계산의 반복 표시는 독립지식/평가표본으로 합산하지 않는다. 세부 분모·검증·산출물은 EP192를 따른다.
