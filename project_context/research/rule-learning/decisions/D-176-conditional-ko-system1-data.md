# D-176 — 조건부 KO와 관측 KO의 분리

- 상태: Accepted
- 날짜: 2026-10-21
- 승인: 사용자 조건부 확정 KO 학습자료 표시 요청

EP198의 단일 관측 결과를 확정 KO로 재해석하지 않는다. 원본은 보존하고 조건부 계산 근거 미확인으로 연결한다.
새 EP199는 실제리플레이의 종/기술을 출처로 하되 정확한 제어세트·HP·명중/비급소 조건과 피해범위를 명시한 별도 문제다.
원경기 숨은세트/피해범위를복원했다고주장하지않는다. min/max와HP 비교의3분류는 명시조건에서만 성립한다.
피해범위가제공되는판정과제이며배틀최적행동·실제KO확률·원경기의확정KO 판정과구분한다.
