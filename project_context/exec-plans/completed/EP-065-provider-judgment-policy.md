# EP-065 — 공급자 판단 오류의 전체 중단 제외

- 상태: Completed
- 생성일: 2026-09-21
- 승인: 사용자 “provider의 판단관련 오류는 전체 실험 중단으로 이어지지 않도록 메뉴얼을 수정해. 계속 끊긴다.”
- 관련: D-074, RESEARCH_DESIGN §11.2, C-046, EP-062/064

## 목표·범위

공급자 판단 오류와 실행·입력 결함을 구분하는 공통 규칙 및 운영 매뉴얼을 수정한다.
INDEX/CHARTER, 연구 설계·계약과 겹치는 EP-062/064를 확인했다.
문서 작업이며 실행 코드 수정·유료 호출·실험 재개는 포함하지 않는다.
과거 EX-047/048의 source·원자료·당시 판정·Blocked를 보존한다.

## 완료 기준

- [x] 판단 오류의 비중단 처리·경기 실패 격리·기술 오류 구분을 원문과 매뉴얼에 반영
- [x] 등록 경로·색인·현재 상태와 실행기 지원 한계를 명시
- [x] 문서 차이·링크·사례를 대조하고 과거 동결 기록 보존 확인

## 검증·진행

- 구현 전 범위 등록. 비실험 문서 작업이므로 복구·재수집·실험 시계는 해당 없음.
- 완료 시 변경 문서 링크와 사례 검토 결과를 여기에 기록한다.

## 결과 및 증거

- RD §11.2/C-046, INDEX 절차, 운영 매뉴얼, plan template·ADR/색인·STATUS를 동기화했다.
- 변경 문서9개의 로컬 링크와 새 anchor를 검사했고 미해결 링크0이었다. 완료 이동 후 참조도 재검사했다.
- 사례 대조: 합계0.99 및 선택0.24/다른 후보0.25는 합법 선택 그대로 진행;
  전략/설명 오류도 계속; 실행 불가능한 응답은 해당 경기 실패;
  공유 입력 결함은 기술 복구 규칙, 통신 오류는 기존 transport 계약으로 분리했다.
- 수정 전 문서와 차이를 대조했다. 과거 EX·active EP-062/064·원자료·실행 코드 변경0,
  추가 API 호출0이다. 문서 작업이므로 runtime 테스트는 실행하지 않았다.

  새 계약의 runtime 지원 완료나 과거 실험 재개를 주장하지 않는다.
