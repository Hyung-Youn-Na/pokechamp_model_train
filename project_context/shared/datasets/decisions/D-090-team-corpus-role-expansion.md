# D-090 — 팀 데이터 기반 열람 역할 DB 확장

- Status: Accepted
- Date: 2026-09-22
- 승인: 사용자가 실제 세트 기반 보완(선택1)을 명시적으로 선택.

## 결정

Metamon modern_replays의 로컬 Gen9 OU 팀25192개와 고정13팀에 등장하는409종을
열람 DB의 모집단으로 삼는다. 기존44종 편집과 추가64종의 검토된 역할은 보존하고,
미작성301종 및 기존 종의 누락된 실제 세트 기능은 실제 기술/특성/아이템과
고정 Gen9 효과에 기반한 조건부 역할 추론으로 보완한다. 종/폼 identity를 합치지 않는다.

추론 역할은 실제 통계로 검증한 OU prior가 아니므로 prior=null로 저장한다.
기존 역할에 추가한 근거는 supporting에 배치하고, 일치 검증과 규칙별 유래를 별도 evidence에 둔다.
열람본의 source/notes/status 제외 선호는 유지하지만 출처 자체는 별도 보존한다.
observed_usage는409종 전체에서 동일하게 팀 파일 기반 비가중 집계로 다시 만든다.
중복 팀 파일은 입력 레코드 빈도로 포함하고 독립 경기/현재 메타 모집단으로 해석하지 않는다.
새 버전 team-pool-role-db-v2는 원본1.1.0 검증기용 교체 파일이 아니다.

## 경계·해석

실제 세트에 기계적 기능이 있다는 조건부 추론이며, 주역할/실전성/효능을 검토 완료로 승격하지 않는다.
모든 세트에 역할을 붙이기 위한 일반 공격 fallback은 금지한다. 미부여 목록·분모를 보존한다.
노력치 추론·종 이름만으로 스피드 부스트 확정·현재 HP/상대 조건의 날조는 하지 않는다.
기존에 삭제한 Zamazenta speed_control, Heatran defensive_check는 복원하지 않는다.
이 결정은 운영 프롬프트·팀 샘플링·실험 처치의 변경 승인이 아니다.
