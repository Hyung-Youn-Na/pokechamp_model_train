# D-091 — 검토 완료108종으로 팀 후보 제한

- Status: Accepted
- Date: 2026-09-22
- 승인: “이미 상당한 팀 구성 숫자이므로 일단은 108종으로 구성된 팀 리스트로 제한하겠습니다.”

## 결정

현재 팀 후보는 Metamon modern_replays Gen9 OU에서 원본 역할 DB의 reviewed108종만으로
구성된 파일 목록으로 제한한다. 6슬롯 모두 정확한 종/폼 ID가 허용 목록에 속해야 한다.
세트별 역할 매칭 여부는 추가 필터로 사용하지 않으며 파일별 기술·도구 차이를 유지한다.
종 조합 중복 제거·무작위 샘플링·새 대진 생성은 수행하지 않는다.

## 적용 경계

검토 완료는 출처 기반 역할 주석이 있다는 뜻이며 실제 모든 세트의 역할 확정이나
팀의 합법성·경쟁력을 보장하지 않는다. D-090의409종 확장 자료는 보존하고,
이번 결정은 현재 사용할 팀 후보 목록의 범위를 정한다.
새 실험은 이 후보 목록을 참조하되 실제 대진·예산·평가 조건은 해당 EX에서 고정한다.
과거 동결 실험이나 상속 upstream 팀 로더의 기본 동작은 변경하지 않는다.
