# D-170 — 연구 목적별 문서 배치와 분산 규범 원문

- 상태: Accepted
- 날짜: 2026-10-20
- 승인: 사용자의 구조 개편 계획 선택 및 “Implement the plan.”

## 결정

연구 질문·목적을 원문의 기본 소속으로 삼고 D·EP·EX 식별자는 유지한다.
계획은 상태와 관계없이 같은 위치에 두며 상태는 개별 원문에서 읽는다.
공통 규범은 중앙 문서에, 주제별 설계·계약·구성은 해당 주제 문서에 둔다.
각 원문의 적용 범위와 authority를 INDEX에서 명시한다.
이는 D-004의 유형·상태별 배치와 단일 파일 규범 원칙, INDEX의 문서 이동 금지를
현재 문서의 조직·탐색에 한해 대체한다. 당시 승인과 연구 내용은 소급 변경하지 않는다.

문서 이동·링크 교정과 매뉴얼·실행기의 원문 조회 조정을 허용한다.
기존 동결 실행 패키지·protocol 사본·보고서·원자료·봉인·모델·환경은 이동하거나 변경하지 않는다.
기존 연구 조건·성적·분모·중단·미완료 판정과 승인 범위는 보존한다.
상태·방법·모델별 색인은 원문과 탐색 등록부로 생성하며 규범이나 실행 승인이 아니다.

## 범위와 근거

원문은 한 곳에만 두고 다른 목적·방법에서 연결한다. 과거 보고서의 경로는 안내 문서로 연결하고,
실행기는 등록 ID로 원문과 적용 규범을 조회하여 동결한다. 다른 연구선 checkout은 변경하지 않는다.
현재 연구 원문 466건과 중앙 문서의 누적을 해결하며 현재/과거 적용 범위를 구분한다.
