# EP-038 — 기본 IO 테스트 설명 오류 기입 명시 선택

- 상태: Completed
- 생성일: 2026-09-14
- 책임자: Codex
- 관련: [D-050](../decisions/D-050-io-explanation-review-opt-in.md), C-009/C-021 및 새 C-032
- 승인 근거: 현재 사용자 지시 「설명 오류를 추가하는 것은 별도 지시사항이 없으면 기본 IO 알고리즘 테스트에서는 적용하지 않도록」.

## 목표·범위

앞으로 기본 IO 알고리즘 테스트에서 설명 오류 사후 검토·기입을 기본 작업/완료 조건으로 상속하지 않는다.
별도 명시 지시가 있을 때만 검토·annotation 추가를 수행하도록 연구 설계·계약·계획 라우팅·운영 문서를 정비한다.
기본 테스트는 일반 IO 실행·입출력 동작·성능 확인이며, 별도 요청한 설명/요약 의미 평가와 구분한다.

## 맥락·불변 조건

기존 EP-011/018/020/030/032/035는 개별 의미/설명 검토 요구가 있거나 중단 이력을 가진다.
기존 실험·평가·미검토·Blocked·원자료·annotation·viewer는 보존한다. 과거 완료 여부를 소급 변경하지 않는다.
`ab_head_to_head_report`는 기존 review.json을 선택적으로 읽고 `direct32_report`는 명시 review가 있을 때만
annotation을 쓴다. viewer는 기존 annotation을 표시할 뿐 설명 오류를 자동 판정·기입하지 않는다.
따라서 이번 변경은 에이전트 작업 기본 지침이며 runtime/schema/prompt/계산 경로 수정은 필요하지 않다.
IO 형식·합법 행동·입력/계산/전송·실행 실패·무결성 검사와 원문/reasoning 기록·표시는 유지한다.
새 유료 호출·배틀·과거 실험 재개/재생성0.
