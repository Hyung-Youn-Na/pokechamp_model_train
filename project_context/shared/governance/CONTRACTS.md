# 문서·연구선 운영 — 실행 계약

이 문서는 **개편 전 중앙 문서의 서문·연구선 안내를 당시 범위로 보존**한다.
아래 본문의 “이 문서”, “현재”, “원문 소유권”은 이전 시점의 문서를 가리킨다.
현재 권한 배치·작업 절차는 [루트 INDEX](../../INDEX.md), 현재 목표는 [CHARTER](../../CHARTER.md),
진행 상태는 [STATUS](../../STATUS.md)가 소유한다. 이전 실험의 규범 참조·해석 범위는 보존한다.


D-170에 따라 중앙 문서의 관련 절을 이전한 편집 원문이다. 연구 설계·계약·구성의 domain authority와 각 절의 적용 버전·조건은 유지한다.
과거 날짜·실험·D별 절의 “현재”, “이번”, “Current”는 해당 당시 범위다. 현재 실행 여부와 승인은 개별 계획 및 전체 상태 색인에서 확인한다.
다른 주제의 기록을 인용하더라도 해당 원문의 소유권·범위를 이전하지 않는다.

# 계약 (Contracts)

이 문서는 아래에 나열한 semantic contract의 authoritative source다. Link된 code와 상세
reference document는 현재의 정확한 field catalog 및 initialization evidence다. Implementation
file을 변경해도 이 contract가 조용히 재정의되지는 않는다. 충돌은
[`INDEX.md`](../../INDEX.md)의 hierarchy를 따른다.

D-148/EX-095의 새 모델 jev35b-nvfp4는 전용 interpreter와 공식 Choice 엔진을 사용한다.
장부 앞단의 중복 방지·원문/usage 보존을 유지하며 세부 진입조건은
[EX-095](../../research/planner-executor/experiments/EX-095-jev35b-nvfp4-sample.md)를 따른다.

D-149/EX-096의 명시 repeat 정책은 확률 차이만 진단으로 기록한다. 필드 부재/strict의 기존
차단과 선택 일치·분포/매핑·입력/usage·자원 검사는 유지하며 당시 동결 기록을 바꾸지 않는다.
