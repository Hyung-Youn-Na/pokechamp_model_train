# EP-186 — Blocked 관리 분류 결과

기존 Blocked 계획35건을 별도 [관리 색인](../../../catalog/blocked.md)으로 분류했다.
원래 EP·EX의 상태·조건·성적·실패/무효 판정과 파일 위치는 변경하지 않았다.
분류 정책은 [D-171](../decisions/D-171-blocked-classification.md), 작업은
[EP-186](../plans/EP-186-blocked-classification.md)에 기록한다.

## 분류

| 관리 분류 | 계획 수 | 판단 기준 |
|---|---:|---|
| 해결 대기 | 0 | 장애와 현재 이어갈 필요가 모두 확인된 항목 없음 |
| 후속 해결·종결 | 15 | 교정·재실험·계승 또는 승인된 조건 변경으로 후속 범위 완료 |
| 진행 종료 | 2 | 해당 실행/추가 작업의 명시적 사용자 종료 지시 |
| 확인 필요 | 18 | 원래 과제의 잔여 범위·후속 대체 범위·현재 진행 필요가 불명확 |

분류 이유, 관련 EX, 후속 EP와 판단 근거는 `catalog/blocked.json`에서 관리하고
색인에 그대로 표시한다. 중복 상태·성적을 별도로 저장하지 않는다.
전체 plans 색인에는 분류별 집계·연결을 두고 Paused는 별도 구역에 표시한다.

## 주요 판단과 한계

- EP-140 → EP-141: 교정 v6의 신규64경기 완료를 연결한다. 원실험의 실패/미실행은 유지한다.
- EP-134 → EP-137: 정상23경기 계승과 신규9경기 평가 완료를 연결한다.
- EP-179 → EP-180: 변경 통신·시간 정책의 신규32경기 완료다. 통신 문제의 영구 해소를 뜻하지 않는다.
- EP-154 → EP-155 → EP-156: 승인된 기준 변경과 후속 샘플 완료다. 원 strict 반복성 gate 통과를 뜻하지 않는다.
- EP-163 → EP-164: backend를 바꾼 후속 평가 완료다. 원 SIGTERM 발신원은 여전히 미확정이다.
- EP-108: 후속 배틀에서는 재현성 문제를 복구했지만 원 오프라인 test는 수행하지 않았다. 확인 필요로 둔다.
- EP-119: 후속 학습 계승 완료가 원 viewer 전수 검증 timeout을 소급 충족하지 않는다.
- EP-035·041: 해당 실행·추가 검토/감시의 명시적 종료 근거를 사용했다. 연구 주제 전체를 폐기한 것은 아니다.

후속 완료가 있는 모든 과거 계획을 자동 종결하지 않았다. 조건 변경·부분 복구의 차이를
기록했고, 해결 대기에 새 연구나 재개 지시를 추정하여 추가하지 않았다.
분류는 관리 정보이며 원실험 성공, 효과 입증, 현재 실행 승인이 아니다.

## 검증

생성 동기화·분류 대상35건의 누락/중복·관련 ID 연결을 검사했다.
새 미분류 Blocked의 확인 필요 표시, Paused 제외, 원문 불변, 불충분한 종결 근거 거부를
CPU 검사로 확인했다. 실험 실행기·학습·API·GPU 호출은 이 작업에 포함하지 않는다.
관련15검사가 통과했고, 기존 EP/EX298개 원문 변경0 및 링크383개 검사를 확인했다.
상세 검사 결과는 EP-186 완료 기록에 둔다.
