# D-172 — 배틀 viewer UI 규격과 변경 기록

- 상태: Accepted
- 날짜: 2026-10-20
- 승인: 현재 대화에서 EX-108 복원형·기본 탭 고정·리플레이 자동 이동을 선택하고 문서·절차 계획의 구현을 지시함.

## 맥락

C-047은 내보내기·원문·오프라인 열람 요건을 정하지만 공통 화면의 버전과 변경 이력을
정하지 않았다. 실험별 생성기가 달라 EX-108에는 EP-177의 화면 복원이 필요했다.
EX-108의 구성과 C-073의 리플레이 동기화는 각각 구현 근거가 있으나, 하나의 생성기가
새 공통 규격을 모두 충족한다는 검증은 없다.

## 결정

`battle-viewer-ui-v1`을 [뷰어 계약](../CONTRACTS.md#battle-viewer-ui-v1)에 정의한다.
EX-108의 기본 5개 탭·배치를 기준으로 삼고, 턴·결정 선택 시 영상 일시정지 및 턴 시작
이동을 요구한다. 기본 탭 뒤에 선언한 확장 탭을 추가하며 첫 화면은 요청 탭이다.
운영은 [연구 매뉴얼](../../../RESEARCH_MANUAL.md#battle-viewer-workflow),
이력은 [CHANGELOG](../CHANGELOG.md)에서 연결한다.

채택 이후 이 연구선에 신규 등록하는 배틀 실험부터 적용한다. 이 범위에서 D-049의
응답 우선 노출 및 D-144/C-073의 계획 기본7탭 규칙 중 화면 우선순위·탭 구성은 v1로
대체한다. 과거 Decision의 당시 내용·적용 근거는 보존하고 현재 계약에 범위 경계를 적는다.
원문 접근·관측 cutoff·공개 정보·원자료 보존 등 나머지 계약은 유지한다.

규격의 의미를 변경할 때는 새 Decision과 다음 UI 규격 버전을 기록한다.
규격 내 확장·표시 교정은 렌더러 판본과 변경일지로 추적하며 승인 근거는 INDEX를 따른다.
EX에는 규격·생성기 소스·확장 탭을 고정하고 EP에는 지원 확인·검증 근거를 연결한다.

## 거절한 대안

- 실험별 기본 탭·첫 화면 변경: 공통 탐색 경험을 유지하려는 사용자 선택과 맞지 않는다.
- 이번에 공통 코드 통합·과거 뷰어 일괄 재내보내기: 사용자가 선택한 문서·절차 범위 밖이다.
- EX-108을 그대로 v1 인증 구현으로 지정: 영상 자동 이동이 없어 새 요구사항을 충족하지 않는다.

## 영향

이번 작업은 규격·절차의 확정이다. 런타임 API·원자료 schema·생성기·기존 내보내기와
실험 판정을 변경하지 않는다. 새 실험은 실행 전에 사용할 생성기의 지원을 확인하며,
미지원 기능은 해당 실험의 선행 구현 작업으로 등록한다. 현재 문서 완료가 생성기의
자동 적용·v1 지원 완료나 후속 구현의 실행 승인을 뜻하지 않는다.
진행 중·중단·동결 실험에는 소급하지 않으며 과거 뷰어 재내보내기는 별도 승인 범위다.
