
B3 REQUEST CHANGE FORMAT
recent_events keeps the identical packet order and event_seq, but protocol becomes lines. A string line is raw protocol including its line ending, unchanged. A request record uses request_index counting from 0 within this input and eol for its original line ending. The first request_base is the complete B1-filtered request. Every later record has base_request equal to the preceding request_index and request_delta applied to that reconstructed request. No prior model call or out-of-window state is needed. A delta {"replace":value} replaces the whole value, including complete arrays; null is a literal value. An object delta has delete (keys removed), set (new keys and full values), patch (recursive changes to existing keys). Omitted keys retain their previous values. Deletion is distinct from setting null or an empty array/object. Unchanged party arrays need not be repeated; any array change replaces the entire array, preserving Pokemon/move order. Apply all request records in packet and line order. Expanding a record yields |request| plus its complete reconstructed JSON and eol. This is exact structural encoding, not a summary or inferred tactical history.
