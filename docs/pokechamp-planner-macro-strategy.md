# Planner 역할·승리 경로·자원 관리 안내

## 목적과 적용 범위

사용자가 요청한 관점은 포켓몬을 현재 대진의 임무와 자원으로 보고, 상대의 승리 경로를 막으면서
자기 승리 경로를 지키는 거시 전략이다. D-140/EP-146에서 새 planner 기본 guide로 구현한다.
대상은 현재 프로젝트의 Gen9 OU singles다. 모든 프로 선수의 사고를 동일하게 재현했다는 주장이
아니며, 경쟁 싱글 대전 문헌의 일반 원칙을 프롬프트에 적용한 설계다.

원문은 [role-resource-guide-v1.txt](../integration/jev_planner/prompts/role-resource-guide-v1.txt)다.
기존 간결형/조건분기형 역할 지시 뒤에 붙는다. 원 JEV의 계산 해석·일반 게임 규칙 장문은 새
system에 자동 추가하지 않는다. 기존 v6 user 관측·계산·후보·공개 이력과 JEV 행동 지시문은 유지한다.
이 변경은 입력 제거나 역할 DB 변경이 아닌 planner system 안내 처치다.

## 참고 자료와 적용 원칙

2026-10-15에 다음 원문을 확인했다. 특정 세대의 추천 세트·포켓몬별 강약·수치·배틀 규칙은
현재 Gen9에 옮기지 않고, 아래 일반 원칙만 새 안내문으로 재구성했다. 직접 인용문은 사용하지 않는다.

예전 Ubers/BW의 세트·기술 예시는 이 프로젝트의 관측 사실이나 Gen9 정답표가 아니다.
희생·보존은 상황에 따른 선택이며 특정 스타일을 무조건 강제하지 않는다.

## 새 안내의 판단 순서

1. **근거 구분:** 현재 상태, 확인된 능력, 조건부 역할 가설을 구분한다. 자기 role_summary는
   세트가 지원하는 능력이고, 상대 role_summary는 종족의 가능성이다. 상대 실제 세트나 의도로 확정하지 않는다.
2. **현재 임무:** 돌파·마무리·특정 위협 억제·리벤지·안전한 교체·설치기/제거·상태/회복 지원 중
   지금 필요한 일을 판단한다. 한 포켓몬은 여러 일을 맡을 수 있으며 대진이 바뀌면 중요도도 바뀐다.
3. **양측 승리 경로:** 누가/어떤 상호작용으로 이길 수 있고 무엇이 남은 장애물인지 설명한다.
   상대의 공격 담당뿐 아니라 내 경로를 막는 방어·지원 담당도 중요한 목표가 될 수 있다.
4. **보존과 소모:** 체력·상태·유효 PP·도구·회복/진입 기회·필드 턴·Tera를 남은 임무에 따라 평가한다.
   저체력이라는 이유만으로 희생 후보를 정하지 않고, 마무리 담당 외 유일 대응책과 지원 수단도 보호한다.
5. **전략적 교환:** 상대의 어떤 자원을 줄이면 무엇이 가능해지는지 명시한다. 단순히 회복되는
   피해와 지속되는 진전을 구분한다. 희생할 때는 잃는 기능, 남은 필요성, 대체 수단을 확인한다.
6. **가능성·전환:** 현재 대면의 조건부 계산을 보조 근거로 사용한다. 근거 없는 정확한 보존 HP,
   벤치 대면 계산·상대 PP를 만들지 않는다. 위협 제거·역할 상실·정보 공개 등에 따라 경로를 수정한다.
7. **기존 출력으로 전달:** objective는 승리 경로/전제, priorities는 다음 진전/교환,
   preserve는 대상·필요 임무·이유, threats는 상대 경로/내 장애물, tera_policy는 전략적 사용 목적,
   contingencies는 관측 가능한 전환 조건에 대응시킨다.

예를 들어 관측상 A가 마무리 담당이고 상대 B가 그 경로를 막는다면, 계획은
“C로 B를 약화시키는 동안 A와 A의 안전한 진입에 필요한 D를 보존한다”처럼 연결한다.
C가 상대의 다른 위협을 막는 유일한 수단이라면 C의 소모를 다시 검토해야 한다.
이는 형식 설명용 가상 예시이며 실제 GLM 응답이나 검증된 대진 정답이 아니다.

## 설정과 호환

새 load_config는 `prompts.guide` 미지정 시 역할·자원 guide를 동결한다. 파일 경로를 바꾸면
별도 안내문을 사용할 수 있다. `matrix.planner_prompts`의 각 항목에도 `guide` 경로를 지정할 수
있으므로 같은 planner 지시문에 서로 다른 guide를 붙여 비교할 수 있다. 비교·중복 제거는 두
본문을 함께 planner 프롬프트 조건으로 다룬다. guide 원문은 run·오프라인 export에 보존된다.

guide 필드가 없는 과거 준비 설정은 당시 v6 안내 조립을 유지한다. 이미 봉인된 EP-145 자료나
뷰어를 새 안내로 바꾸어 쓰지 않는다. 프롬프트 수정 후 실행은 새로운 prepare 경로를 사용한다.
출력 schema·JEV 지시문·호출 정책·모델 옵션을 함께 바꾸지 않는다.

## 검증의 의미

관련 CPU 검사와 무호출 preview는 메시지 조립·입력 보존·원문 동결·비교 식별을 확인한다.
문헌 근거와 검증 통과는 GLM이 역할을 정확히 추론하거나 승률이 개선됐다는 증거가 아니다.
실제 모델·배틀 평가와 그 조건/예산은 후속 실험에서 정한다.
